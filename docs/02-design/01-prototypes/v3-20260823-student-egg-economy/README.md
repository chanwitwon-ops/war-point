### เส้นทางกดทดลองหลัก (happy path)

1. เปิดไฟล์ → หน้า **ล็อกอิน** → กรอกรหัส `3001` / PIN `1234` → กด "เข้าสู่ระบบ"
2. หน้า **บทเรียนของฉัน** → กด "เปิดคลิป"/"เปิดเอกสาร" หรือ "ให้ AI อ่านออกเสียง" อย่างน้อย 1 บทเรียน → กด "ไปทำแบบทดสอบ"
3. หน้า **ทำแบบทดสอบ** → ตอบครบ 5 ข้อ → กด "ส่งคำตอบ" → กด "ดูผลคะแนน" (ได้แต้มตามจำนวนข้อที่ตอบถูก)
4. หน้า **ผลคะแนน** → เห็นยอดแต้มสะสมรวม/ใช้ได้ → กด "ไปซื้อไข่ตัวแรก" (เพราะยังไม่มีสัตว์เลี้ยง)
5. หน้า **ซื้อไข่** → ใช้ "เครื่องมือทดสอบ" ที่หัวไฟล์ตั้งยอดแต้มเป็น `51` เพื่อให้เดินทางได้ครบทุกขั้นในรอบเดียว → เลือกสายพันธุ์ 1 ใน 3 (ไข่มีปีก/ไข่มีขา/ไข่มีหาง) → กด "ซื้อไข่ (ใช้ 1 แต้ม)"
6. หน้า **สัตว์เลี้ยงของฉัน** → เห็นขั้นไข่ + ตารางต้นทุน + แต้มสเตตัสรวม 50 → กด "ปลดล็อกร่างที่ 1" (ใช้เพิ่ม 5) → ทำซ้ำจนถึงร่างที่ 4 (ใช้เพิ่ม 10, 15, 20 ตามลำดับ) → สังเกตแต้มสเตตัสรวมขยับ 50→100→150→200→250 และค่าสเตตัสรายตัวขยับตามสัดส่วนของสายที่เลือก
7. **[เพิ่ม 2026-08-25]** ในหน้า **สัตว์เลี้ยงของฉัน** เดียวกันนี้ เลื่อนลงมาที่โซน "ดูแลสัตว์เลี้ยงประจำวัน":
   - กด **"ให้อาหาร"** 3 ครั้งติดกัน → สังเกต animation อาหารจางหาย และ "โควตาวันนี้"/"ยอดสะสมรวม" ขยับ +1 ทุกครั้ง (รวม 3) → กดครั้งที่ 4 → เห็นข้อความ **"ตัวละครอิ่มแล้ว"** และตัวเลขทั้งสองไม่ขยับอีก
   - กด **"อาบน้ำ"**, **"ลูบหัว"**, **"เล่น/ออกกำลังกาย"** สลับกันไปจนกว่า "โควตาวันนี้" ครบ **10/10** (สังเกต animation ของแต่ละปุ่มต่างกัน: พื้นหลังฟ้าอ่อนล้อมตัว / สัตว์เลี้ยงเด้ง+หัวใจลอย / สัตว์เลี้ยงวิ่งหายไปแล้วกลับมา) → กด action ใดๆ ต่ออีกครั้ง → เห็นข้อความเชิงบวก **"วันนี้ดูแลเต็มที่แล้ว พรุ่งนี้ค่อยมาใหม่นะ"** และ "โควตาวันนี้" ไม่เกิน 10
   - กด **"จำลองวันใหม่ (รีเซ็ตความหิว+โควตาวันนี้)"** ที่แถบเครื่องมือทดสอบด้านบนสุดของไฟล์ → สังเกต "โควตาวันนี้" กลับเป็น 0/10 และกด "ให้อาหาร" ได้ผลปกติอีกครั้ง (ความหิวรีเซ็ตแล้ว) แต่ **"ยอดสะสมรวม" ไม่ลดลง** ยังคงค้างที่ 10 (หรือมากกว่า ถ้าทำ "ให้อาหาร" ต่อ)
   - กด **"รีเซ็ต / เปลี่ยนสายพันธุ์"** → กด "ยืนยันรีเซ็ต" → สังเกตว่าเมื่อกลับมาสร้างสัตว์เลี้ยงตัวใหม่ "ยอดสะสมรวม" ในโซนดูแลสัตว์เลี้ยงกลับเป็น **0** (ไม่สืบทอดจากตัวเก่า)
8. กด "รีเซ็ต / เปลี่ยนสายพันธุ์" (ถ้ายังไม่ได้กดในขั้นตอนที่ 7) → อ่านเงื่อนไขในโมดัล → กด "ยืนยันรีเซ็ต" → ระบบพากลับไปหน้า **ซื้อไข่** พร้อมยอดแต้มที่ใช้ได้คืนเต็ม (ยอดสะสมรวมของแต้มไม่ลด)
9. หน้า **ร้านไอเทมช่วย** → ซื้อ "ล้างสถานะ" และ/หรือ "ป้องกันการโจมตีถึงตาย" (ถ้ามีแต้มพอ)
10. หน้า **อารีน่า** → เลือกคู่แข่ง (ลองเลือก "ต้นกล้า" ซึ่งยังอยู่ขั้นไข่ เพื่อยืนยัน FE-76) → กด "ยืนยันคู่แข่ง" → ในหน้าต่อสู้ กด "ใช้" ที่ป้ายไอเทม (ถ้ามี) แล้วสังเกตว่าเปลี่ยนเป็น "ใช้แล้ว" → กด "ดูผลการแข่งขัน" → อ่านข้อความยืนยันว่าจบแมตช์แล้วสัตว์เลี้ยงกลับสภาพเดิม ไม่เสียแต้ม ไม่ลดขั้น → กด "เลือกคู่แข่งใหม่" เพื่อวนรอบถัดไป

## ข้อจำกัดของ prototype (สรุป)

- **สิ่งที่จำลอง (mock):** ข้อมูลนักเรียน/บทเรียน/แบบทดสอบทั้งหมด, สัดส่วนแต้มสเตตัสของ 2 ใน 3 สาย, ราคาไอเทม, ค่า HP, ผลแพ้-ชนะของแต่ละแมตช์, คู่แข่งในอารีน่า, กฎการถือครองไอเทม (สมมติว่าใช้ได้ทุกแมตช์), **[เพิ่ม 2026-08-25]** "วันใหม่/เที่ยงคืน" ของระบบดูแลสัตว์เลี้ยง จำลองด้วยปุ่มทดสอบแทนเวลาจริงของเครื่อง เพราะไม่มี backend
- **สิ่งที่ไม่ได้ทำ:** สูตรตัดสินแพ้-ชนะจริง, สูตรคำนวณ HP, การผูกพลังพิเศษกับสายพันธุ์, หน้าจอฝั่งครู, ของแต่งตัว (ยกเลิกแล้ว), ระบบชำระเงิน/รางวัลจริง, **[เพิ่ม 2026-08-25]** หน้าตา/ท่าทางแยกตามอารมณ์ของสัตว์เลี้ยง (นอกขอบเขตตาม spec 20260825-07 หัวข้อ "ไม่อยู่ในขอบเขต"), การใช้ยอดสะสมความผูกพันตัดสินรางวัลท้ายเทอมจริง (ยังเป็นแค่แนวทางในอนาคต ไม่ใช่ acceptance criteria ของรอบนี้)
- **ภาพประกอบสัตว์เลี้ยง/ไข่ทั้งหมดเป็นรูปทรงเรขาคณิต** (วงกลม/วงรี/สามเหลี่ยม/สี่เหลี่ยม) ยังไม่มีอาร์ตเวิร์กจริงตาม DESIGN.md ข้อ 3.7
- **"เครื่องมือสำหรับทดสอบ prototype"** ที่หัวไฟล์ (ตั้งยอดแต้ม) เป็นเครื่องมือช่วยรีวิวเท่านั้น ไม่ใช่ฟีเจอร์ของระบบจริง ถูกทำเครื่องหมายไว้ชัดเจนในหน้าจอ
