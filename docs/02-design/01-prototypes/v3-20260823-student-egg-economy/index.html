บทเรียนของฉัน

เลือกดูคลิป/สื่อ หรือเอกสารที่ครูเตรียมไว้ให้ ก่อนไปทำแบบทดสอบ

เลือกคำตอบที่ถูกที่สุดในแต่ละข้อ แล้วกดส่งคำตอบ

ผลคะแนนของฉัน

ซื้อไข่ตัวแรก

เลือกสายพันธุ์ก่อนซื้อไข่ — สายพันธุ์เลือกได้ตอนซื้อไข่เท่านั้น ไม่ใช่ตอนฟัก (FE-44) ราคาไข่ 1 แต้ม ล็อกแล้วจาก spec

ข้อมูลสายพันธุ์และสัดส่วนแต้มสเตตัส

ทุกขั้นการเติบโต (รวมขั้นไข่) ให้ แต้มสเตตัส +50 แล้วระบบหารลงค่าสเตตัสตามสัดส่วนประจำสายพันธุ์อัตโนมัติ นักเรียนไม่มีหน้าจอจัดสรรเอง (FE-77)

อัลบั้มบันทึกเส้นทางการเติบโต

ประวัติของสัตว์เลี้ยงตัวก่อนๆ ที่เคยเลี้ยงมา — เป็นบันทึกอ่านอย่างเดียว ไม่สามารถกดเพื่อสลับกลับไปใช้ตัวเก่าที่โตแล้วได้ (FE-72/73/74)

สัตว์เลี้ยงของฉัน

ร้านไอเทมช่วยในการต่อสู้

ไอเทมช่วยไม่มีผลต่อค่าสเตตัสของสัตว์เลี้ยง — หมวดของแต่งตัวเดิมถูกยกเลิกแล้วทั้งหมด (FE-25 เลิกใช้ → แทนที่ด้วย FE-78) ราคาค่าสมมติ ยังไม่ล็อกใน spec 06

อารีน่ารายสัปดาห์

ยืนยันรีเซ็ต / เปลี่ยนสายพันธุ์?

สิ่งที่จะเกิดขึ้นทันที (spec 02 หัวข้อ ซ.6):

  • สัตว์เลี้ยงตัวปัจจุบันกลับไปเริ่มที่ ขั้นไข่ที่ยังไม่ได้ซื้อ ไม่มีข้อยกเว้น
  • ยอดแต้มที่ใช้ได้จะกลับมาเท่ากับยอดสะสมรวมทั้งหมด (คืนเต็ม) — ยอดสะสมรวมไม่ลดตลอด
  • ต้องจ่าย 1 แต้ม ซื้อไข่ใหม่อีกครั้งในขั้นถัดไป (เลือกสายพันธุ์ใหม่ได้ตอนซื้อไข่)
  • ตัวเก่าจะถูกบันทึกไว้ในอัลบั้มเส้นทางการเติบโต แต่ไม่สามารถสลับกลับมาใช้งานได้อีก
