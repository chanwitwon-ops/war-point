## Click-through path ที่แนะนำ

1. **หน้า 1** — กด "เข้าสู่ระบบด้วยบัญชี Google" → เข้าหน้าภาพรวมชั้นเรียนทันที
2. **หน้า 2 (ภาพรวมชั้นเรียน)** — ลองเปลี่ยน "เรียงลำดับตาม" และ "กรองข้อมูล" ดูแถวเปลี่ยนจริง สังเกตสัญลักษณ์เตือน ▲ บนแถวรหัส 4103 และ 4106 (ชี้เมาส์ค้างเพื่อดูเหตุผล) กดปุ่ม "รีเซ็ต PIN" ที่แถวใดก็ได้ดู modal PIN ใหม่ กดปุ่ม "ตรวจ/บันทึกคะแนน" ที่แถวหนึ่งเพื่อกระโดดไปหน้า 6 พร้อมไฮไลต์แถวนั้น
3. **หน้า 3 (จัดการรายชื่อ)** — เลือกไฟล์ตัวอย่าง (ปุ่มเลือกไฟล์ไม่จำเป็นต้องเลือกไฟล์จริงก็กด "อ่านไฟล์" ได้) → เลือกคอลัมน์รหัส → กด "นำเข้ารายชื่อจากไฟล์" ดูแถวใหม่ 3 แถวเพิ่มในตาราง ลองทำซ้ำกับฝั่งลิงก์ Google Sheets ลองเพิ่มนักเรียนทีละคน ลอง "รีเซ็ต PIN" / "ล้างชื่อเล่น" / "ปิดการใช้งาน" แล้วกลับไปหน้า 2 เพื่อดูว่าคนที่ปิดใช้งานไม่ปรากฏอีก
4. **หน้า 4 (ลงบทเรียน)** — ลองเพิ่มบทเรียนทั้ง 3 ทาง (ลิงก์ / ไฟล์ / พิมพ์เอง) แล้วกรอกหัวข้อในกล่อง "ให้ AI ช่วยค้นหาคลิป" กด "ค้นหาด้วย AI" จะเห็นคลิปที่เสนอ 2 รายการอยู่ในส่วน "รอครูอนุมัติ" — สังเกตว่ายังไม่ปรากฏในรายการ "บทเรียนที่เผยแพร่แล้ว" จนกว่าจะกด "อนุมัติ"
5. **หน้า 5 (สร้างแบบทดสอบ)** — เลือกรูปแบบ ตั้งคะแนนเต็ม/จำนวนรอบ/วันเปิด-ปิด กด "สร้างแบบทดสอบ" แล้วกลับไปหน้า 2 เพื่อดูว่ามีคอลัมน์ใหม่ของชุดนี้เพิ่มเข้ามาในตารางภาพรวมทันที
6. **หน้า 6 (ตรวจงาน/บันทึกคะแนน)** — ในกลุ่ม "ข. ชุดที่ครูตรวจเอง" หาแถวที่สถานะ "ส่งแล้ว รอตรวจ" (เช่น รหัส 4106 หรือ 4109 ในชุดใบงาน) กรอกคะแนนแล้วกด "บันทึกคะแนน" แล้วกลับไปหน้า 2 เพื่อดูว่าคะแนนใหม่ไปแสดงในหน้าภาพรวมทันที
7. **หน้า 7 (จัดการแข่งขัน)** — ลองสลับ 4 โหมดจับคู่ทีละโหมด ("นักเรียนเลือกเอง" มีคู่ตัวอย่างให้ดูตั้งแต่แรก / "ครูกดสุ่ม" กดปุ่มสุ่มดูคู่เปลี่ยน / "ครูเลือกเอง" เลือกนักเรียน 2 คนแล้วกด "เพิ่มคู่" / "ตั้งอัตโนมัติ" เปิดสวิตช์ดูคู่ถูกสร้างให้) กด "ประกาศผลการแข่งขัน" ดูสถานะเปลี่ยนจาก "ยังไม่ประกาศ" เป็น "ประกาศแล้ว" พร้อมผลแพ้-ชนะ แล้วกด "ฉายผลในคาบโฮมรูม" เพื่อดูโหมดฉายทีละคู่ และดูสถิติผู้ชนะสะสมด้านล่างเปลี่ยนตาม
8. **หน้า 8 (ส่งออกคะแนน)** — เลือก "คะแนนแยกรายชุด" หรือ "คะแนนรวม" → เลือกช่องทาง (ลิงก์ Sheets ต้องกรอกลิงก์ก่อน หรือดาวน์โหลดไฟล์เลือกรูปแบบ) → เลือกคอลัมน์ปลายทางของแต่ละข้อมูล → กด "ตรวจสอบข้อมูลก่อนส่ง" ดูรายงานแถวที่ถูกข้าม (รหัส 5001, 5002 สมมติว่าไม่ตรงกับระบบ) → กด "ยืนยันส่งคะแนน" ดูข้อความสำเร็จพร้อมเวลาที่ส่งล่าสุด

## ⛔ ทำไมหน้านี้จงใจไม่แสดงแต้มและขั้นการเติบโตของสัตว์เลี้ยงนักเรียน

ตาม [[../../../01-requirements/01-spec/20260821-04-teacher-class-overview|spec 04]] หัวข้อ "ข. ข้อมูลที่หน้านี้จงใจไม่แสดง — พร้อมเหตุผล":

- ครูไม่จำเป็นต้องรับรู้เรื่องสัตว์เลี้ยงของนักเรียน ถ้าครูต้องมานั่งดูว่าใครอยู่ขั้นไหนแล้วเรียงว่าใครสูสีกับใคร ระบบจะกลาย**เพิ่ม**ภาระครูแทนที่จะ**ผ่อน**ภาระ ซึ่งขัดกับข้อจำกัดหลักของโปรเจกต์
- การจับคู่แข่งขันจึงใช้วิธีให้ **นักเรียนเลือกเองว่าอยากสู้กับใคร** (FE-42) เป็นวิธีหลัก แทนที่จะให้ครูจับคู่ตามระดับ
- หลักการที่ผู้ใช้ระบุไว้: *"เราไม่ได้ต้องการความเท่าเทียม แต่เรากำลังส่งเสริมให้เด็กอยากขึ้นไปเท่าเทียมกับเพื่อน"*

ผลต่อ prototype นี้:

- หน้า 2 (ภาพรวมชั้นเรียน) แสดงได้เฉพาะสถานะทำ/ไม่ทำ คะแนน เวลาเข้าใช้งานล่าสุด และสัญลักษณ์เตือน — ไม่มีคำว่าแต้ม/ขั้น/ค่าพลัง/สัตว์เลี้ยงของนักเรียนปรากฏที่ใดในหน้านี้เลย
- หน้า 7 (จัดการแข่งขัน) แสดงได้เฉพาะ **รายชื่อคู่แข่ง (รหัส+ชื่อเล่น)** และ **ผลแพ้-ชนะ** เท่านั้น ไม่มีค่าพลัง ขั้น หรือแต้มปรากฏใน DOM แม้แต่จุดเดียว — ผลแพ้-ชนะถูกจำลองด้วยการสุ่ม 50/50 ในไฟล์นี้ (ในระบบจริงตัดสินด้วยค่าพลังจากขั้นการเติบโตที่ครูไม่เห็น)
- ทุกหน้าใช้ **รหัสประจำตัว + ชื่อเล่น** เท่านั้นในการอ้างถึงนักเรียน ไม่มีชื่อ-นามสกุลจริงปรากฏที่ใดในไฟล์ (รวมถึงตัวอย่างคอลัมน์ในหน้านำเข้ารายชื่อที่ระบุชัดว่า "จะไม่นำเข้าชื่อจริง")

## ข้อมูลจำลอง (mock data) — เจ้าของเดียวตาม DESIGN.md ข้อ 4.8

นักเรียนตัวอย่างมี **13 คน** (ย่อจากห้องจริง ~30 คนตาม spec 03 เพื่อความกระชับของ prototype) ประกาศไว้ในตัวแปร `MOCK` ที่ต้นสคริปต์ของ `index.html` เท่านั้น มีชุดแบบทดสอบตัวอย่าง 3 ชุด (ปรนัยครูสร้างเอง / ใบงาน / ปรนัย AI) ที่มีสถานะทำ/ไม่ทำและคะแนนต่างกันในแต่ละคน ทุกหน้าจอที่ต้องอ้างค่าเหล่านี้อ่านจาก `state` ตัวเดียวเท่านั้น ไม่มีการพิมพ์ตัวเลขซ้ำแยกไฟล์ — เมื่อสร้างแบบทดสอบใหม่หรือบันทึกคะแนนใหม่จากหน้าใดก็ตาม หน้าภาพรวมชั้นเรียนจะอัปเดตพร้อมกันทันทีเพราะอ่านจาก state เดียวกัน

## ข้อจำกัดของ prototype (สิ่งที่จำลองไว้ / สิ่งที่ไม่ได้ทำ)

- **ไม่เชื่อมต่อ Google จริง** ปุ่มล็อกอินและปุ่มนำเข้า/ส่งออกผ่าน Google Sheets เป็นการจำลองผลลัพธ์ทั้งหมด ไม่มีการเรียก API ภายนอกจริง
- **ไม่มีการ parse ไฟล์ Excel/CSV จริง** ปุ่ม "เลือกไฟล์" เป็น `<input type="file">` จริงแต่ไม่มีการอ่านเนื้อหาไฟล์ ระบบแสดงตัวอย่างคอลัมน์และเพิ่มนักเรียนชุดคงที่ (mock batch) เพื่อสาธิตกลไกเลือกคอลัมน์รหัสเท่านั้น
- **ไม่มีระบบ AI จริง** ทั้งการค้นหาคลิป การอ่านออกเสียง และการออกข้อสอบเป็นข้อความจำลอง
- **การตัดสินผลการแข่งขันใช้การสุ่ม 50/50** แทนสูตรค่าพลังจริงจากขั้นการเติบโต เพราะหน้าครูไม่มีสิทธิ์เห็นค่าพลังเลยแม้ในข้อมูลเบื้องหลัง (ตาม spec 04)
- **ไม่มีการล็อกอินของนักเรียนหรือหน้าจอฝั่งนักเรียนในไฟล์นี้** — ดูฝั่งนักเรียนได้ที่ [[../v1-20260821-student-learn-and-pet/index.html|v1 prototype ฝั่งนักเรียน]] (คนละไฟล์ ไม่ได้แก้ไขในงานนี้)
- **ไม่มีบัญชี/หน้าจอสำหรับผู้ปกครอง และไม่รองรับหลายห้องเรียน** ตามระดับ Won't ใน feature-list
- **ค่า PIN ที่แสดงในตารางเป็นค่าจำลองในหน่วยความจำของเบราว์เซอร์เท่านั้น** ปิด/รีเฟรชหน้าแล้วข้อมูลทั้งหมดจะรีเซ็ตกลับเป็นค่าเริ่มต้น (ไม่มี backend/database จริง)
- **ยังไม่ทดสอบกับครูจริง** เรื่องว่าการเทียบรหัสประจำตัวกับชื่อเล่นแทนชื่อจริงจะทำให้ครูสับสนหรือไม่ในทางปฏิบัติ (ยังเป็น Open Question ในเอกสารต้นทาง)
