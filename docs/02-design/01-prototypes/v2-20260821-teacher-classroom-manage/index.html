ภาพรวมชั้นเรียน

ดูสถานะทำ/ไม่ทำแบบทดสอบรายชุด คะแนนรายคน และใครไม่เข้าใช้งานนาน ในหน้าเดียว — หน้านี้ไม่แสดงแต้มหรือขั้นการเติบโตของสัตว์เลี้ยงของนักเรียน (จงใจตาม spec 04)

สัญลักษณ์เตือน ▲ ควรดูแล ปรากฏเมื่อนักเรียนไม่เข้าใช้งานเกิน วัน หรือยังไม่มีชุดใดที่ทำ/ตรวจเสร็จเลย — เกณฑ์และรูปแบบสัญลักษณ์เป็นค่าสมมติ (spec 04 ยังไม่ล็อก) ไม่ใช่การไฮไลต์สีทั้งแถว (ตาม DESIGN.md ข้อ 3.6)

ก. ชุดที่ระบบตรวจให้อัตโนมัติ FE-16

ครูไม่ต้องกรอกคะแนนของชุดกลุ่มนี้ ระบบคำนวณให้ทันทีที่นักเรียนส่งคำตอบ

ข. ชุดที่ครูตรวจและบันทึกคะแนนเอง FE-17

กรอกคะแนนให้นักเรียนที่ส่งงานแล้ว ค่านี้จะไปแสดงในหน้าภาพรวมชั้นเรียนทันทีหลังกดบันทึก

จัดการแข่งขันรายสัปดาห์

ครูตัดสินใจเรื่องรางวัลจริงเอง ระบบให้ข้อมูลสถิติเป็นตัวช่วยเท่านั้น

    ส่งออกคะแนน

    เลือกข้อมูล เลือกช่องทาง เลือกคอลัมน์ปลายทาง ตรวจรายงานแถวที่ถูกข้าม แล้วครูกดส่งเอง — ระบบไม่เขียนอะไรลงสมุดคะแนนของครูจนกว่าครูจะกดยืนยัน

    1. เลือกข้อมูลที่จะส่งออก FE-63

    2. เลือกช่องทางส่งออก

    3. เลือกคอลัมน์ปลายทาง FE-68

    ครูเลือกเองว่าข้อมูลแต่ละอย่างลงคอลัมน์ไหน ระบบไม่บังคับจัดสมุดคะแนนใหม่

    4. ตรวจสอบข้อมูลก่อนส่ง FE-69/FE-70

    5. ยืนยันส่ง FE-71
