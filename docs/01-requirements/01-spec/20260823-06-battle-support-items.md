# ไอเทมช่วยในการต่อสู้และการใช้แต้มส่วนเกิน (Battle Support Items & Surplus Points)

- **วันที่บันทึก:** 2026-08-23
- **สถานะ:** Confirmed
- **อ้างอิง:** [[20260821-02-pet-points-and-weekly-arena|20260821-02-pet-points-and-weekly-arena]] (หลัก), [[20260821-00-problem-statement|20260821-00-problem-statement]], [[20260821-01-lesson-and-quiz-system|20260821-01-lesson-and-quiz-system]], [[20260821-05-score-export-and-gradebook|20260821-05-score-export-and-gradebook]]

## บริบท / ที่มา

ผู้ใช้เปลี่ยนแนวคิดร้านค้าของระบบสัตว์เลี้ยง จาก "ของแต่งตัวเพื่อความสวยงาม" เป็น **"ไอเทมช่วยลดความซวยจากดวงในการต่อสู้"** และอธิบายเหตุผลเชิงออกแบบที่อยู่เบื้องหลังตัวเลข 51 แต้มไว้ด้วย — ต้องบันทึกเหตุผลนี้ให้ครบ เพราะเป็นตัวปิดความเสี่ยงที่เอกสาร [[20260821-02-pet-points-and-weekly-arena|20260821-02-pet-points-and-weekly-arena]] เปิดค้างไว้

เหตุผลที่ผู้ใช้ระบุ (เรียบเรียงจากคำพูดของผู้ใช้ ไม่ตัดสาระออก):

- ผู้ใช้ตั้งต้นทุนพัฒนาถึงขั้นสุดท้ายไว้ที่ **51 แต้ม** เพราะถ้านำคะแนนสอบจริงในระบบไปใช้ **เด็กทุกคนที่พัฒนาถึงร่างสุดท้ายจะการันตีว่าได้เกรด 1 แน่นอน ไม่มีการติด 0**
- ดังนั้น **แต้มส่วนที่เหลือเกิน 51 แต้ม ให้เป็นโบนัส** ไว้ซื้อของลดความซวยจากดวง **เพื่อเป็นรางวัลของเด็กที่ตั้งใจทบทวนและทำคะแนนได้ดี**
- จุดยืนของผู้ใช้: **"เราไม่ได้สนใจความเท่าเทียม เพราะคนที่ตั้งใจต้องได้ผลตอบแทนที่คู่ควร"** — สอดคล้องกับจุดยืนเดิมที่บันทึกไว้ในข้อ ฉ. ของ [[20260821-02-pet-points-and-weekly-arena|20260821-02-pet-points-and-weekly-arena]] ที่ว่า "เราไม่ได้ต้องการความเท่าเทียม แต่เรากำลังส่งเสริมให้เด็กอยากขึ้นไปเท่าเทียมกับเพื่อน"

**ผลที่ตามมาซึ่งต้องเขียนให้ชัด:** ความเสี่ยงที่ [[20260821-02-pet-points-and-weekly-arena|20260821-02-pet-points-and-weekly-arena]] เปิดค้างไว้ว่า "ต้นทุนทั้งเส้นเพียง 51 แต้มอาจทำให้เด็กถึงร่างที่ 4 เร็วเกินไปแล้วไม่มีอะไรให้ทำต่อ" **ถูกปิดด้วยกลไกนี้** เพราะแต้มหลังจากนั้นมีที่ใช้ต่อคือร้านไอเทม ไม่ใช่ตันอยู่ที่ร่างที่ 4

## ความต้องการ (Requirement)

### ก. ไอเทมช่วยมาแทนของแต่งตัวทั้งหมด

- **ร้านค้าขายไอเทมช่วยเท่านั้น หมวด "ของแต่งตัว" ถูกยกเลิก** ไม่ใช่เพิ่มหมวดใหม่ควบคู่ — ผู้ใช้เลือกชัดเจนว่า "ไอเทมช่วยมาแทนของแต่งตัวทั้งหมด"
- **ตัวอย่างไอเทมที่ผู้ใช้ระบุ (เป็นตัวอย่าง ยังไม่ใช่รายการครบ):**
  - **ล้างสถานะได้ 1 ครั้ง** (ล้างผลของพลังพิเศษ เช่น ไฟไหม้ / ติดพิษ / มึนงง ตามข้อ ช. ของ [[20260821-02-pet-points-and-weekly-arena|20260821-02-pet-points-and-weekly-arena]])
  - **ป้องกันการโจมตีถึงตายได้ 1 ครั้ง**
- **ราคา/คะแนนของไอเทมยังไม่กำหนด** ผู้ใช้ระบุว่า "ตั้งไว้เป็นตัวอย่างก่อน"
- **ห้ามแต่งรายการไอเทมเพิ่มเองโดยไม่มีต้นทางจากผู้ใช้** (กฎเดียวกับพลังพิเศษในข้อ ช. ของ [[20260821-02-pet-points-and-weekly-arena|20260821-02-pet-points-and-weekly-arena]]) — เพิ่มได้เมื่อผู้ใช้ระบุ ไม่ใช่ผู้ช่วยคิดเพิ่มเอง

### ข. HP ในแมตช์ — แนวคิดใหม่

- **เพิ่มแนวคิด HP เข้ามาในกลไกการต่อสู้** เมื่อ **HP หมด = ตาย = จบแมตช์** และนับเป็นแพ้
- **"ตาย" เป็นสภาพภายในแมตช์เท่านั้น** — ไม่ขัดกับกฎเดิมในข้อ ค. ของ [[20260821-02-pet-points-and-weekly-arena|20260821-02-pet-points-and-weekly-arena]] ที่ว่า "การแพ้ไม่มีผลเสียใดๆ เลยต่อสัตว์เลี้ยง ไม่เสียแต้ม ไม่ลดขั้น สัตว์เลี้ยงไม่เปลี่ยนสภาพ" เพราะเมื่อจบแมตช์แล้วสัตว์เลี้ยงกลับสภาพเดิมทุกอย่าง **กฎข้อ ค. เรื่องการแพ้ไม่มีผลเสีย ยังใช้อยู่เต็มรูปแบบ ห้ามแก้**
- ไอเทม **"ป้องกันการโจมตีถึงตาย 1 ครั้ง"** = กันไม่ให้ HP ถึง 0 ได้ 1 ครั้งต่อแมตช์

### ค. ผลกระทบต่อกฎ "ผลการแข่งมาจากขั้นการเติบโตล้วนๆ"

นี่เป็นจุดที่ต้องเขียนอย่างระวังเพราะเป็นการแก้กฎที่เอกสารยืนยันไว้แล้ว แยกเป็น 2 ชั้น:

- **ชั้นที่ไม่เปลี่ยน:** **ค่าสเตตัสยังมาจากขั้นการเติบโตล้วนๆ** — ไอเทมช่วย**ไม่เพิ่มค่าสเตตัส**ของสัตว์เลี้ยง กฎนี้ยังอยู่ครบ
- **ชั้นที่เปลี่ยน:** **ผลการแข่งขันไม่ได้ถูกตัดสินจากขั้นการเติบโตเพียงอย่างเดียวอีกแล้ว** — ไอเทมช่วยเข้ามามีผลต่อผลของแมตช์ได้
- **เหตุผลที่ยังรักษาหลักการเดิมไว้ได้:** หลักการเดิมในข้อ ง. ของ [[20260821-02-pet-points-and-weekly-arena|20260821-02-pet-points-and-weekly-arena]] คือ "ตรงไปตรงมา เด็กเข้าใจทันที และโยงกลับไปที่การเรียนชัดเจน" — กลไกใหม่ยังโยงกลับการเรียนได้ครบ เพราะ**ไอเทมซื้อด้วยแต้มที่มาจากคะแนนสอบส่วนเกิน** ความได้เปรียบจึง trace กลับไปที่ความตั้งใจเรียน ไม่ใช่ปัจจัยภายนอกหรือการสุ่ม
- **หมายเหตุการตีความ:** การแยก 2 ชั้นนี้เป็นการสรุปจากคำตอบของผู้ใช้ที่อธิบายเป็นเหตุผลเชิงออกแบบ **ไม่ได้เลือกจากตัวเลือกที่เสนอ** — ถ้าผู้ใช้ต้องการให้ไอเทมไม่มีผลต่อผู้ชนะเลย ต้องกลับมาแก้ข้อนี้

## ขอบเขต (Scope)

- **อยู่ในขอบเขต:** ร้านไอเทมช่วย (แทนของแต่งตัว), แนวคิด HP ในแมตช์, การใช้แต้มส่วนเกิน 51 แต้มเป็นโบนัสซื้อไอเทม, การที่ไอเทมมีผลต่อผลแมตช์แต่ไม่เพิ่มค่าสเตตัส
- **นอกขอบเขตรอบนี้:** รายการไอเทมครบชุดและราคาจริง, สูตรคำนวณ HP, สูตรตัดสินแพ้-ชนะ, การผูก 51 แต้มกับเกณฑ์เกรดจริงในสมุดคะแนนของครู, อาร์ตเวิร์ก/ไอคอนของไอเทม

## Acceptance Criteria

- [ ] ร้านค้าไม่มีหมวดของแต่งตัวเหลืออยู่ มีเพียงไอเทมช่วย
- [ ] ไอเทมช่วยไม่ทำให้ค่าสเตตัสของสัตว์เลี้ยงเปลี่ยนแปลง
- [ ] ไอเทม "ล้างสถานะ" ใช้ได้ 1 ครั้งต่อแมตช์แล้วหมดไป
- [ ] ไอเทม "ป้องกันการโจมตีถึงตาย" กันไม่ให้ HP ถึง 0 ได้ 1 ครั้งต่อแมตช์
- [ ] เมื่อ HP ของฝ่ายใดถึง 0 แมตช์จบทันทีและฝ่ายนั้นนับเป็นแพ้
- [ ] เมื่อจบแมตช์ สัตว์เลี้ยงที่ HP หมดไม่เสียแต้ม ไม่ลดขั้น และกลับสภาพเดิมทุกอย่าง
- [ ] การซื้อไอเทมหักจากยอดแต้มที่ใช้ได้ ไม่กระทบยอดแต้มสะสมรวม
- [ ] นักเรียนที่จ่ายครบ 51 แต้มถึงร่างที่ 4 แล้ว ยังใช้แต้มส่วนเกินซื้อไอเทมต่อได้
- [ ] ไอเทมไม่ทำให้ผลของการแพ้มีบทลงโทษเพิ่มขึ้นจากที่ spec 02 ข้อ ค. กำหนดไว้

## ประเด็นที่ยังไม่ชัดเจน (Open Questions)

1. **รายการไอเทมครบชุดและราคายังไม่กำหนด** — ผู้ใช้ระบุแค่ 2 ตัวอย่าง และบอกว่าคะแนนยังไม่กำหนด ตั้งเป็นตัวอย่างก่อน
2. **HP เป็นค่าสเตตัสตัวหนึ่งหรือแยกจากค่าสเตตัส ยังไม่ตัดสิน** — ปัจจุบันรายการค่าสเตตัส placeholder ใน spec 02 ข้อ ช. มีเพียง ความเร็ว / พละกำลัง / ความแม่นยำ **ไม่มี HP** ถ้า HP เป็นค่าสเตตัส ต้องเพิ่มเป็นค่าที่ 4 และ**การหารแต้มสเตตัส 50 แต้มต่อขั้นตามสัดส่วนสายต้องคิดใหม่ทั้งหมด** (กระทบ FE-77 โดยตรง)
3. **ข้อกังวลที่ต้องเฝ้าดู — ข้ออ้าง "ถึงร่างสุดท้ายแล้วการันตีเกรด 1 ไม่ติด 0" ยังไม่มีกลไกในระบบรองรับ:** เพราะ spec 02 ข้อ ก. ให้**ครูเป็นผู้ตั้งคะแนนเต็มต่อชุดเอง** และ [[20260821-05-score-export-and-gradebook|20260821-05-score-export-and-gradebook]] ให้ครูส่งออกคะแนนเข้าสมุดคะแนนของตัวเอง — ระบบจึงยังไม่ได้ผูกตัวเลข 51 แต้มกับเกณฑ์ผ่านจริงของครูคนใด **ต้องนิยามความสัมพันธ์ระหว่างแต้มในระบบกับเกณฑ์เกรดจริงก่อน จึงจะอ้างการันตีนี้ได้** ระบุให้ชัดว่านี่เป็นข้อสังเกตของผู้ช่วย ผู้ใช้ยังไม่ได้ตัดสิน
4. **สูตรตัดสินแพ้-ชนะและวิธีคำนวณ HP ยังไม่มี** (ต่อเนื่องจาก Open Question เดิมของ spec 02 เรื่องสูตรตัดสินแพ้-ชนะ ให้อ้างอิงโยงกัน)
5. **กฎการถือครองไอเทมยังไม่กำหนด** — ใช้ได้กี่ชิ้นต่อแมตช์, ซื้อซ้ำได้ไหม, เก็บข้ามสัปดาห์ได้ไหม
6. ~~เมื่อรีเซ็ต/เปลี่ยนสายพันธุ์ (ข้อ ค. ของ spec 02) ไอเทมที่ซื้อไว้หายไปหรือไม่ และได้แต้มค่าไอเทมคืนด้วยไหม — กฎเดิมคือคืนแต้มที่ใช้ไปทั้งหมดจนยอดใช้ได้เท่ากับยอดสะสมรวม ซึ่งถ้าตีความตรงตัวจะคืนค่าไอเทมด้วย และเปิดช่องให้ซื้อไอเทมแล้วรีเซ็ตเพื่อเอาแต้มคืนวนไปเรื่อยๆ เป็นช่องโหว่ที่ต้องปิดก่อนพัฒนา~~ **[ปิดแล้ว 2026-08-23]** เมื่อนักเรียนรีเซ็ต/เปลี่ยนสายพันธุ์ (ข้อ ค. ของ spec 02) ระบบ**คืนแต้มทั้งหมดที่เคยใช้ไปกับสัตว์เลี้ยงตัวนี้ รวมแต้มที่ใช้ซื้อไอเทมช่วยด้วย** ทำให้ยอดแต้มที่ใช้ได้ (available_points) กลับมาเท่ากับยอดสะสมรวม (total_earned_points) เต็มจำนวนตามกฎข้อ ข.3 เดิมทุกประการ ไม่มีข้อยกเว้น — **แต่ไอเทมทั้งหมดที่นักเรียนถือครองอยู่ ณ ตอนรีเซ็ตจะถูกเคลียร์ทิ้งไปพร้อมกันในจังหวะเดียวกัน (ไม่สามารถเก็บไอเทมข้ามการรีเซ็ตไปใช้ต่อได้)** นี่คือกลไกที่ปิดช่องโหว่เดิม: นักเรียนจะไม่ได้ทั้งไอเทมและแต้มคืนพร้อมกัน ถ้าเลือกรีเซ็ตก็ต้องแลกกับการเสียไอเทมที่ถือครองอยู่ทั้งหมดไปด้วย สิ่งเดียวที่ยังคงอยู่ต่อเนื่องข้ามการรีเซ็ตคือบันทึกเส้นทางการเติบโต (FE-72/FE-73) เท่านั้น
