## บริบท / ที่มา

ผู้ใช้ (ผู้ออกแบบระบบ) กังวลว่ากลไก "เปลี่ยนชนิดสัตว์เลี้ยง/รีเซ็ตตัวละคร" ที่มีอยู่แล้ว (FE-26 ใน [[../01-spec/20260821-02-pet-points-and-weekly-arena|20260821-02-pet-points-and-weekly-arena]]) อาจทำให้นักเรียนไม่รู้สึกผูกพันกับสัตว์เลี้ยงของตัวเอง เพราะรีเซ็ตทิ้งได้ตลอดโดยไม่มีอะไรสูญเสียทางความรู้สึก จึงต้องการเพิ่มกลไกดูแลสัตว์เลี้ยงแบบทามาก็อตจิ/ดิจิม่อน (ให้อาหาร, อาบน้ำ, ลูบหัว, เล่น/ออกกำลังกาย) เพื่อสร้างความผูกพันทางอารมณ์ระหว่างนักเรียนกับสัตว์เลี้ยงของตัวเอง และเป็นช่องทางแฝงที่กระตุ้นให้นักเรียนเปิดแอปสม่ำเสมอ ซึ่งอาจโยงไปสู่การทบทวนบทเรียนผ่านวงจรแรงจูงใจหลักที่มีอยู่แล้วใน [[../01-spec/20260821-02-pet-points-and-weekly-arena|20260821-02-pet-points-and-weekly-arena]]

**ระบบนี้เป็นระบบใหม่ที่แยกขาดโดยสิ้นเชิงจากวงจรแต้ม-เติบโต-ต่อสู้เดิม** — ไม่แก้ไขตัวเลข กติกา หรือรหัสใดๆ ที่มีอยู่แล้วในสเปกเดิม เป็นเพียงชั้นความผูกพัน (bonding layer) ที่ซ้อนอยู่บนสัตว์เลี้ยงตัวเดิม

## ความต้องการ (Requirement)

### ก. Action ดูแล 4 แบบ (ล็อกตายตัวในรอบนี้)

ผู้ใช้ยืนยันชัดเจนว่าในรอบนี้มี action ดูแลสัตว์เลี้ยงเพียง 4 แบบเท่านั้น:

1. **ให้อาหาร**
2. **อาบน้ำ**
3. **ลูบหัว**
4. **เล่น/ออกกำลังกาย**

**ถ้าต้องการเพิ่ม action แบบอื่นในอนาคต ต้องเปิด requirement ใหม่แยกต่างหาก ห้ามขยายรายการนี้เองในเอกสารนี้หรือในเอกสารลูกที่ตามมา (feature-list, prototype, technical spec)**

### ข. ความหิว (ค่าซ่อนเฉพาะ Action ให้อาหาร)

สัตว์เลี้ยงแต่ละตัวมีค่า **"ความหิว"** เป็นค่าสถานะภายใน (hidden internal state) เพียงตัวเดียว:

- **ความหิว** — เป็นค่าซ่อนล้วนๆ **ไม่แสดงเป็นหลอด/เกจ/ตัวเลขให้นักเรียนเห็นบนหน้าจอ** ผูกกับ action "ให้อาหาร" โดยเฉพาะเท่านั้น ใช้ภายในระบบเพื่อตัดสินว่า "อิ่มแล้วหรือยัง" สำหรับวันนั้น
- **เกณฑ์ "อิ่มแล้ว" ล็อกที่ 3 ครั้ง/วัน** — กด "ให้อาหาร" สำเร็จ (มีผลจริง) ได้สูงสุด 3 ครั้งต่อวันเท่านั้น ครั้งที่ 1-3 แต่ละครั้งได้ผลปกติ (ความหิวเพิ่มขึ้น + ค่าความผูกพัน +1 หน่วย/ครั้ง รวม 3 หน่วยจากการให้อาหารอย่างเดียวถ้ากดครบ 3 ครั้ง) ตั้งแต่ครั้งที่ 4 เป็นต้นไปในวันเดียวกันถือว่า "อิ่มแล้ว" ไม่มีผลใดๆ ต่อความหิวและไม่สะสมค่าความผูกพันเพิ่มอีก
- **Action "อาบน้ำ", "ลูบหัว", "เล่น/ออกกำลังกาย" ไม่มีค่าสถานะ/หลอดซ่อนใดๆ ทั้งสิ้น** — กดได้ไม่จำกัดจำนวนครั้งอย่างแท้จริง ไม่มีเงื่อนไข "เต็มแล้วไม่มีผล" สำหรับ 3 action นี้เลย (ต่างจาก "ให้อาหาร" ที่มีเพดาน 3 ครั้ง/วันของตัวเอง)

**กลไกกันสแปมของ "ให้อาหาร":** กดได้ไม่จำกัดจำนวนครั้งในแต่ละวัน แต่ถ้ากด "ให้อาหาร" สำเร็จครบ 3 ครั้งแล้ว (ความหิว "เต็มแล้ว"/อิ่มแล้วสำหรับวันนั้น) การกด "ให้อาหาร" ซ้ำ (ครั้งที่ 4 เป็นต้นไป) **จะไม่มีผลใดๆ ต่อค่าความหิวอีก และไม่สะสมค่าความผูกพันเพิ่ม** — พร้อมกันนั้นระบบต้องแสดง **feedback message ชัดเจนว่า "ตัวละครอิ่มแล้ว"** ให้ผู้เล่นเห็นทุกครั้งที่กด (ห้ามกดเงียบๆ ไม่มีอะไรเกิดขึ้น) — นี่คือกลไกกันสแปมหลักเพียงอย่างเดียวของ action นี้ **ไม่มี cooldown แยกต่างหาก** (ไม่มีการล็อกปุ่มชั่วคราว ไม่มีเวลารอระหว่างการกด)

**ความหิวไม่ลดแบบต่อเนื่องตามเวลา (ไม่ใช่ decay รายชั่วโมง):**

- ค่าความหิวรีเซ็ตกลับเป็น 0 (ว่าง/ยังไม่อิ่ม) ทุกเที่ยงคืน — เริ่มวันใหม่ว่างเปล่าเสมอ ไม่ว่าเมื่อวานจะอิ่มแค่ไหนก็ตาม
- ระบบใช้แค่ตรรกะ "วันที่ปัจจุบันกับวันที่บันทึกไว้ล่าสุดเป็นวันเดียวกันหรือไม่" เพื่อตัดสินว่าต้องรีเซ็ตค่าความหิวหรือไม่ — **ไม่ต้องมี background job หรือคำนวณ decay ตามจำนวนชั่วโมงที่ผ่านไป**
- เจตนาการออกแบบ (ตามที่ผู้ใช้ระบุ): เน้นเก็บข้อมูลแบบ "วันต่อวัน" ไม่กดดันให้นักเรียนต้องเข้ามาดูแลทุกกี่ชั่วโมง ลดความเครียดจากการดูแลสัตว์เลี้ยงแบบ real-time

### ค. ค่าความผูกพัน (Bonding Point)

ค่าความผูกพันเป็นค่าใหม่ที่**แยกขาดจากความหิว และแยกขาดจากคะแนน/แต้มที่ใช้ได้โดยสิ้นเชิง**:

- **1 หน่วยความผูกพัน ต่อการกด action สำเร็จ 1 ครั้ง เท่ากันทุก action ไม่มีน้ำหนักต่างกัน** ("ให้อาหาร" ตอนความหิวยังไม่เต็ม, "อาบน้ำ", "ลูบหัว", "เล่น/ออกกำลังกาย" ทุก action ให้ +1 หน่วยเท่ากันหมด) — ตัวเลขนี้เป็นตัวเลขตายตัวที่ผู้ใช้ยืนยันแล้ว
- **สะสมเฉพาะตอนที่กด action สำเร็จจริง** — สำหรับ "ให้อาหาร" หมายถึงตอนที่ความหิวยังไม่เต็ม ถ้ากด "ให้อาหาร" ตอนความหิวเต็มแล้ว จะ**ไม่สะสม**ค่าความผูกพัน ส่วน "อาบน้ำ", "ลูบหัว", "เล่น/ออกกำลังกาย" ไม่มีเงื่อนไข "เต็มแล้วไม่มีผล" ของตัวเอง จึงสะสมได้ทุกครั้งที่กด (ภายใต้เพดานรวมข้อถัดไป)
- **เพดานสะสมสูงสุด 10 หน่วยต่อวัน รวมทุก action เข้าด้วยกัน** — ตัวเลขนี้เป็นตัวเลขตายตัวที่ผู้ใช้ยืนยันแล้ว **เป็นเพดานรวม ไม่ใช่เพดานแยกต่อ action** ผลจากการที่ "ให้อาหาร" มีเพดานของตัวเอง (3 ครั้ง/วัน = สูงสุด 3 หน่วยจาก "ให้อาหาร" อย่างเดียว แยกจากเพดานรวม): ถ้ากด "ให้อาหาร" ครบ 3 ครั้งก่อนถึงเพดานรวม 10 นักเรียนยังกดสะสมอีก 7 หน่วยที่เหลือต่อได้ผ่านอีก 3 action ("อาบน้ำ", "ลูบหัว", "เล่น/ออกกำลังกาย") ที่ไม่มีเพดานของตัวเอง จนกว่าจะถึงเพดานรวม 10/วัน
- เมื่อกดจนถึงเพดานรวม 10/วันแล้ว การกด action ใดๆ ต่อไป **จะไม่สะสมค่าความผูกพันเพิ่มอีก** และระบบต้องแสดง **feedback message เชิงบวก ไม่กดดัน** บอกผู้เล่น (เช่น "วันนี้ดูแลเต็มที่แล้ว พรุ่งนี้ค่อยมาใหม่นะ" หรือข้อความทำนองเดียวกัน) ทุกครั้งที่กด
- **ต้องแยกเป็น 2 ค่าคนละตัวชัดเจน ห้ามปนกัน:**
  1. **"โควตาหาแต้มต่อวัน" (daily earn quota)** — คือตัวนับที่ใช้เทียบกับเพดาน 10 หน่วย/วันข้างต้น (จำนวนหน่วยที่ยัง "หาเพิ่มได้" ในวันนั้นๆ) **ตัวนับนี้เท่านั้นที่รีเซ็ตกลับเป็น 0 ทุกเที่ยงคืน** พร้อมกับความหิว (ใช้ตรรกะ "วันเดียวกันหรือไม่" แบบเดียวกับข้อ ข.) เพื่อเปิดโควตาใหม่ให้หาแต้มเพิ่มได้อีกสูงสุด 10 หน่วยในวันถัดไป
  2. **"ยอดสะสมรวมของค่าความผูกพัน" (total accumulated bonding score)** — คือค่าที่เก็บไว้ระยะยาว **ไม่รีเซ็ตทุกเที่ยงคืน** สะสมเพิ่มขึ้นเรื่อยๆ ทุกครั้งที่นักเรียนทำ action สำเร็จ (นับรวมจากทุกวัน เช่น วันนี้ได้ 8 หน่วย พรุ่งนี้ได้ 5 หน่วย ยอดสะสมรวมจะเป็น 13 ไม่ใช่รีเซ็ตกลับ 0 ทุกวัน) ค่านี้จะรีเซ็ตกลับเป็น 0 **ก็ต่อเมื่อเปลี่ยนสายพันธุ์/รีเซ็ตตัวละคร (FE-26) เท่านั้น** ตามที่ระบุไว้แล้วในข้อ ง.
  3. **เหตุผล:** ยอดสะสมรวมนี้คือค่าที่ครูจะเรียกดูได้ในอนาคต (ถ้าอยากใช้ตัดสินแจกรางวัลท้ายเทอม ตามที่บันทึกไว้ในหัวข้อ "ไม่อยู่ในขอบเขต") — ถ้ารีเซ็ตทุกเที่ยงคืน ยอดจะไม่มีความหมายให้ครูดูเปรียบเทียบกันได้เลย เพราะทุกคนจะเหลือแค่ค่าของวันล่าสุดวันเดียว ไม่ใช่ภาพรวมทั้งเทอม **การเก็บยอดสะสมไว้ไม่ได้แปลว่าต้องสร้างหน้าจอ/ฟีเจอร์แจกรางวัลใหม่ตอนนี้** (ยังคงอยู่นอกขอบเขตตามเดิม) แค่ต้องแน่ใจว่าตัวเลขที่เก็บไว้จริงไม่ถูกล้างทิ้งทุกวันจนไม่มีข้อมูลให้ดูย้อนหลัง — ระบบยังไม่มีผลอัตโนมัติอื่นใดจากค่ายอดสะสมนี้
- **ค่าความผูกพันไม่มีผลใดๆ ต่อคะแนน/แต้มที่ใช้ได้ (FE-23)** และ**ไม่มีผลใดๆ ต่อค่าสเตตัสต่อสู้ (FE-77)** ทั้งสิ้น — ระบบนี้เป็นชั้นความผูกพันล้วนๆ ไม่ใช่ช่องทางหารายได้แต้มหรือค่าสเตตัสเพิ่มเติม

### ง. ค่าความผูกพันรีเซ็ตพร้อมตัวละคร

- เมื่อเกิดการเปลี่ยนสายพันธุ์/รีเซ็ตตัวละคร (FE-26 ใน [[../01-spec/20260821-02-pet-points-and-weekly-arena|20260821-02-pet-points-and-weekly-arena]]) **ค่าความผูกพันสะสมของตัวใหม่เริ่มที่ 0 เสมอ ไม่สะสมข้ามตัว**
- เหตุผล (ตามที่ผู้ใช้ยืนยัน): ความเป็นธรรมชาติและความเท่าเทียม — นักเรียนที่ไม่เคยรีเซ็ตเลยไม่ควรถูกนักเรียนที่รีเซ็ตบ่อยแซงหน้าด้วยค่าความผูกพันสะสมข้ามตัวแบบไม่เป็นธรรม ผู้ใช้ยืนยันแนวทางนี้ชัดเจนแล้วว่าดีที่สุด ไม่ใช่แค่หนึ่งในตัวเลือกที่เสนอ

### จ. Animation แบบ overlay ง่ายๆ ซ้อนบนท่ายืนปกติ

รูปแบบ animation ของแต่ละ action **ไม่ใช่ท่าทางเต็มตัวแยกใหม่ตามอารมณ์** แต่เป็น overlay ง่ายๆ ซ้อนทับบนท่ายืนปกติของสัตว์เลี้ยง ตัวอย่างที่ผู้ใช้อธิบาย:

- **ให้อาหาร** — รูปอาหารค่อยๆ ถูกกัดหายไปทีละคำ (ซ้อนหน้าตัวสัตว์เลี้ยงท่ายืนปกติ)
- **ลูบหัว** — รูปมือขยับอยู่ตรงหัวสัตว์เลี้ยง (ซ้อนบนท่ายืนปกติ)
- **เล่น/ออกกำลังกาย** — ตัวสัตว์เลี้ยงวิ่งหรือบินหายไปจากจอสักพักแล้วกลับมา (เหมือนถูกปล่อยไปเล่นสนุกแล้วกลับ)
- **อาบน้ำ** — ตัวสัตว์เลี้ยงแช่อยู่ในบ่อน้ำร้อน/ออนเซ็น (เห็นแค่ส่วนบนของตัวโผล่จากน้ำ ล้อมด้วยไอน้ำ/ก้อนหิน) ซ้อนบนท่ายืนปกติ เป็นเวลาสั้นๆ ประมาณ 3-5 วินาที

**เหตุผลเชิงขอบเขตที่ต้องบันทึกไว้:** ระบบสัตว์เลี้ยงมีอยู่แล้ว 3 สายพันธุ์ × 5 ขั้น (ไข่ + ร่าง 1-4) = อย่างน้อย 15 ภาพเป็นต้นทุนขั้นต่ำอยู่แล้ว (อ้างอิง FE-44 เลือกสายพันธุ์, FE-24 ขั้นการเติบโต) ถ้าเพิ่มท่าทาง/หน้าตาแยกตามอารมณ์แบบเต็มตัวจะคูณเป็นภาระงานศิลป์มหาศาลสำหรับ prototype ที่ต้อง self-contained แบบ inline SVG ตาม `DESIGN.md` (ห้ามอ้างอิงรูปภาพหรือ CDN ภายนอก) — การใช้ overlay ง่ายๆ ซ้อนท่ายืนปกติจึงเป็นทางเลือกที่คุมต้นทุนงานศิลป์ได้ในรอบนี้

## ขอบเขต (Scope)

### อยู่ในขอบเขต

- Action ดูแล 4 แบบ: ให้อาหาร, อาบน้ำ, ลูบหัว, เล่น/ออกกำลังกาย
- ความหิว (ค่าซ่อนเฉพาะ action "ให้อาหาร" เท่านั้น) พร้อมตรรกะ "กดสำเร็จได้สูงสุด 3 ครั้ง/วัน ครั้งที่ 4 เป็นต้นไปถือว่าอิ่มแล้วกดซ้ำไม่มีผล" — ส่วน action "อาบน้ำ", "ลูบหัว", "เล่น/ออกกำลังกาย" ไม่มีหลอด/ค่าสถานะซ่อนใดๆ ของตัวเอง กดได้ไม่จำกัดจำนวนครั้ง
- การรีเซ็ตความหิวและ "โควตาหาแต้มต่อวัน" ของค่าความผูกพันทุกเที่ยงคืน (รีเซ็ตทั้งหมดพร้อมกันตามวันปฏิทิน ไม่ใช่นับถอยหลังเป็นชั่วโมง) — **ยอดสะสมรวมของค่าความผูกพันไม่รีเซ็ตทุกเที่ยงคืน** (ดูข้อ ค.)
- ค่าความผูกพันสะสมรายวัน (เพดานโควตา 10 หน่วย/วันรวมทุก action) ที่แยกขาดจากความหิวและจากแต้ม/ค่าสเตตัสต่อสู้โดยสิ้นเชิง พร้อมยอดสะสมรวมระยะยาวที่ไม่รีเซ็ตทุกเที่ยงคืน (สะสมต่อเนื่องจนกว่าจะเปลี่ยนสายพันธุ์/รีเซ็ตตัวละคร)
- การรีเซ็ตค่าความผูกพันเป็น 0 เมื่อเปลี่ยนสายพันธุ์/รีเซ็ตตัวละคร (ผูกกับ FE-26)
- Animation แบบ overlay ง่ายๆ ซ้อนท่ายืนปกติสำหรับแต่ละ action

### ไม่อยู่ในขอบเขต (ยังไม่ทำในรอบนี้ ไม่ใช่ "ไม่ทำเลย")

- **หน้าตา/ท่าทางแยกตามอารมณ์ของตัวละคร** (เช่น หน้าเศร้าตอนหิวมาก, ท่าทางเต็มตัวแยกใหม่ตามระดับความหิว) — เลื่อนไปเฟสถัดไป ทำก็ต่อเมื่อทดลองใช้ระบบดูแลสัตว์เลี้ยงนี้แล้วได้รับการตอบรับดีจากผู้ใช้จริงก่อน
- **การขยาย action เกิน 4 แบบ** — ถ้าต้องการเพิ่มในอนาคตต้องเปิด requirement ใหม่แยกต่างหาก
- **การใช้ค่าความผูกพันตัดสินรางวัลท้ายเทอมอย่างเป็นทางการ** — ปัจจุบันเป็นเพียง "แนวทางที่เป็นไปได้" ที่ผู้ใช้เอ่ยถึงเท่านั้น (ครูอาจให้รางวัลนักเรียนที่ค่าความผูกพันสูงสุดท้ายเทอม ในทำนองเดียวกับแนวทางที่มีอยู่แล้วใน FE-46 เรื่องสถิติผู้ชนะการแข่งขันที่ครูตัดสินใจให้รางวัลเอง) — **บันทึกไว้เป็นทิศทางในอนาคต/แรงจูงใจประกอบเท่านั้น ไม่ใช่ acceptance criteria ของรอบนี้** เพราะยังไม่มีกลไก/หน้าจอ/กติการางวัลที่ล็อกจริง ถ้าจะทำจริงต้องเปิด requirement ใหม่แยกเพื่อกำหนดกติการางวัลและ UI ให้ครูดู

## Acceptance Criteria

- [ ] กด "ให้อาหาร" ในครั้งที่ 1-3 ของวันนั้น (ยังไม่ถึงเกณฑ์อิ่ม) → แต่ละครั้งความหิวเพิ่มขึ้น และค่าความผูกพันของวันนั้น +1 หน่วยต่อครั้ง (ถ้ายังไม่ถึงเพดานรวม 10 หน่วย/วัน) รวมสูงสุด 3 หน่วยจากการให้อาหารอย่างเดียวถ้ากดครบ 3 ครั้ง
- [ ] กด "ให้อาหาร" ตั้งแต่ครั้งที่ 4 เป็นต้นไปในวันเดียวกัน (ถือว่าอิ่มแล้ว) → ไม่มีผลใดๆ ทั้งต่อความหิวและต่อค่าความผูกพัน พร้อมทั้งระบบแสดง feedback message ว่า "ตัวละครอิ่มแล้ว" ให้ผู้เล่นเห็นทุกครั้งที่กด
- [ ] กด "อาบน้ำ", "ลูบหัว", หรือ "เล่น/ออกกำลังกาย" กี่ครั้งก็ได้ (ไม่มีเงื่อนไข "เต็มแล้วไม่มีผล" สำหรับ 3 action นี้) → แต่ละครั้งที่กด ค่าความผูกพันของวันนั้น +1 หน่วยเสมอ จนกว่าจะถึงเพดานรวม 10 หน่วย/วัน
- [ ] เมื่อค่าความผูกพันของวันนั้นถึงเพดานรวม 10 หน่วยแล้ว การกด action ใดๆ ต่อไป → ไม่สะสมค่าความผูกพันเพิ่มอีก และระบบแสดง feedback message เชิงบวก/ไม่กดดันบอกผู้เล่นว่าดูแลเต็มที่แล้วสำหรับวันนี้ (ปุ่มยังกดได้ตามปกติ ไม่ถูกปิดใช้งาน/ไม่หายไป)
- [ ] ผ่านเที่ยงคืน (วันที่ปัจจุบันเปลี่ยนจากวันที่บันทึกไว้ล่าสุด) → ค่าความหิว และ "โควตาหาแต้มต่อวัน" ของค่าความผูกพัน กลับเป็น 0 (เปิดโควตาใหม่ให้หาแต้มเพิ่มได้อีกสูงสุด 10 หน่วยในวันถัดไป) โดยไม่ต้องมี background job คำนวณ decay ตามชั่วโมง — **"ยอดสะสมรวม" ของค่าความผูกพันไม่ถูกรีเซ็ต ยังคงค่าเดิมจากเมื่อวานบวกต่อไปเรื่อยๆ**
- [ ] เมื่อนักเรียนเปลี่ยนสายพันธุ์/รีเซ็ตตัวละคร (FE-26) → ค่าความผูกพันสะสมของตัวละครใหม่เริ่มต้นที่ 0 เสมอ ไม่สืบทอด/ไม่สะสมข้ามจากตัวเดิม
- [ ] Action ทั้ง 4 แบบ (ให้อาหาร, อาบน้ำ, ลูบหัว, เล่น/ออกกำลังกาย) ไม่ส่งผลใดๆ ต่อแต้มที่ใช้ได้ (FE-23) และไม่ส่งผลใดๆ ต่อค่าสเตตัสต่อสู้ (FE-77) ไม่ว่ากรณีใด
- [ ] แต่ละ action แสดง animation แบบ overlay ซ้อนบนท่ายืนปกติของสัตว์เลี้ยงตามที่ระบุในข้อ จ. ไม่ใช่ท่าทางเต็มตัวแยกใหม่ตามอารมณ์

## ประเด็นที่ยังไม่ชัดเจน (Open Questions) / ช่องว่างที่พบ (Gap)

1. **ปลายทางการใช้ค่าความผูกพันเป็นเกณฑ์รางวัลท้ายเทอม** (ถ้าจะทำจริงในอนาคต) — ต้องเปิด requirement ใหม่แยกต่างหากเพื่อกำหนดกติการางวัลและหน้าจอให้ครูดู ไม่ใช่ส่วนหนึ่งของเอกสารนี้
