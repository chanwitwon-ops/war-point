## ความต้องการ (Requirement)

1. **ต้องล็อกอินก่อนถึงจะเห็น** — ไม่วางไว้หน้าล็อกอิน ไม่เปิดสาธารณะ ทั้งบทบาทครูและนักเรียนเห็นได้
2. **ตำแหน่ง:** ช่วงบนสุดของหน้าแรกของทัวนาเมนต์ แบ่งเป็น 2 ส่วน
3. **ส่วนที่ 1 — นักเรียนที่คะแนนมากที่สุด:** แสดงเฉพาะ "ครึ่งบน" ของห้อง เพื่อไม่ให้คนอันดับล่างรู้สึกเหมือนถูกประจาน คนครึ่งล่างไม่ปรากฏในรายการเลย
4. **ส่วนที่ 2 — ลำดับผู้ชนะทัวนาเมนต์:** บอกว่าสัปดาห์ไหนใครได้แชมป์
5. **แหล่งที่มาของคะแนน:** มาจาก "การเรียนและการสอบ" เท่านั้น คือคะแนนจากแบบทดสอบที่ครูตรวจแล้ว (ระบบปัจจุบันแปลง 1 คะแนน = 1 แต้ม) — **ไม่มีแต้มกิจกรรมที่ครูให้เองด้วยมือ**
   - **เหตุผล (ผู้ใช้):** ต้องมี log ยืนยันได้ว่าแต้มทุกแต้มมาจากข้อสอบชุดไหน ไม่ใช่ความลำเอียงเลือกที่รักมักที่ชัง
6. **ชื่อที่แสดง** = ชื่อเล่นที่นักเรียนตั้งเองตอนสมัคร เพราะระบบไม่เก็บชื่อจริง ตาม [[20260821-03-student-identity-and-roster|20260821-03-student-identity-and-roster]]

**การตีความที่ assistant ใช้ (ไม่ใช่คำที่ผู้ใช้พูดตรงๆ):** "คะแนนมากที่สุด" = คะแนนรวมสะสมจากแบบทดสอบที่ตรวจแล้วทั้งหมด (= แต้มที่ได้รับทั้งหมด นับรวมแต้มที่ใช้ซื้อ/วิวัฒนาการสัตว์ไปแล้ว ไม่ใช่แต้มคงเหลือ) เพื่อไม่ให้คนที่ใช้แต้มเลี้ยงสัตว์ตกอันดับ

## ขอบเขต (Scope)

- **อยู่ในขอบเขต:** สองส่วนข้างต้น, การต้องล็อกอิน, การแสดงชื่อเล่น, คะแนนจากข้อสอบที่ตรวจแล้วเท่านั้น, การตรวจย้อนได้ว่าคะแนนมาจากไหน
- **ไม่อยู่ในขอบเขต:** แต้มกิจกรรม/โบนัสที่ครูให้เอง, การแสดงอันดับของนักเรียนครึ่งล่าง, การแสดงบนหน้าล็อกอิน/สาธารณะ, ระบบรางวัลเพิ่มเติม, การแสดงตัวเลขอันดับของตัวเองให้คนครึ่งล่าง

## Acceptance Criteria

- [ ] ผู้ที่ยังไม่ล็อกอินเห็น leaderboard ไม่ได้
- [ ] ครูและนักเรียนที่ล็อกอินแล้วเห็นทั้ง 2 ส่วนที่ช่วงบนของหน้าแรกทัวนาเมนต์
- [ ] ส่วนคะแนนแสดงเฉพาะครึ่งบน คนครึ่งล่างไม่ปรากฏชื่อ
- [ ] คะแนนที่ใช้มาจากแบบทดสอบที่ตรวจแล้วเท่านั้น ไม่มีช่องทางให้ครูเพิ่มแต้มด้วยมือ และตรวจย้อนได้ว่ามาจากผลสอบชุดไหน
- [ ] การใช้แต้มซื้อ/วิวัฒนาการสัตว์ไม่ทำให้อันดับลดลง
- [ ] ส่วนแชมป์แสดงว่าแต่ละสัปดาห์ใครเป็นแชมป์ (ชื่อเล่น) เรียงตามเวลา
- [ ] ทุกจุดแสดงชื่อเล่น ไม่มีชื่อจริง
- [ ] (เพิ่ม 2026-11-08) เมื่อจำนวนนักเรียนในห้องเป็นเลขคี่ จำนวนที่ขึ้นโชว์เป็นครึ่งบนที่ปัดขึ้น (เช่น 31 คน โชว์ 16 คน)
- [ ] (เพิ่ม 2026-11-08) ถ้าคะแนนเท่ากันตรงเส้นแบ่งครึ่ง ทุกคนที่มีคะแนนเท่ากับคนสุดท้ายในครึ่งบนขึ้นโชว์ทั้งหมด ไม่ตัดใครออกเพราะลำดับบังเอิญ
- [ ] (เพิ่ม 2026-11-08) นักเรียนที่มีคะแนน 0 ไม่ขึ้นโชว์ในรายการ แต่ถูกนับรวมในจำนวนนักเรียนทั้งห้องตอนคำนวณครึ่งบน
- [ ] (เพิ่ม 2026-11-08) ส่วนแชมป์แสดง "สัปดาห์" เป็นช่วงวันที่ของสัปดาห์นั้น และถ้าสัปดาห์เดียวมีหลายทัวนาเมนต์ แสดงแชมป์ของทุกรายการ
- [ ] (เพิ่ม 2026-11-08) แชมป์ที่ได้จากครูตัดสิน (เสมอเมื่อครบเพดานเทิร์น) แสดงเป็นแชมป์ปกติ พร้อมหมายเหตุเล็กๆ "ครูตัดสิน"
- [ ] (เพิ่ม 2026-11-08) นักเรียนที่ขึ้นโชว์ในส่วนคะแนน แสดงแต้มรวมเป็นตัวเลข
