# ระบบสัตว์เลี้ยง แต้ม และการแข่งขันรายสัปดาห์ (Pet, Points & Weekly Arena)

- **วันที่บันทึก:** 2026-08-21
- **อัปเดตล่าสุด:** 2026-08-21 — เพิ่มการจับคู่แบบนักเรียนเลือกเอง, โหมดฉายผลในห้องเรียน, การเลือกและเปลี่ยนชนิดสัตว์เลี้ยง, ค่าสเตตัสและพลังพิเศษประจำสาย และปิด Open Question 7 ข้อ
- **สถานะ:** Confirmed
- **อ้างอิง:** [[20260821-00-problem-statement|20260821-00-problem-statement]], [[20260821-01-lesson-and-quiz-system|20260821-01-lesson-and-quiz-system]]

## บริบท / ที่มา

- เป็นกลไกแรงจูงใจหลักของเฟสที่ 1 ตาม Problem Statement — แก้ root cause สายที่ 1 โดยทำให้เด็กอยากทบทวนบทเรียนเองโดยไม่ต้องพึ่งผู้ปกครอง
- แนวคิดที่ผู้ใช้เคาะไว้: ให้เด็ก**เลี้ยงสัตว์เลี้ยงเพื่อสร้างความผูกพัน** เด็กจึงอยากเข้ามาเรียนและทำคะแนนให้ดีเพื่อพัฒนาตัวละคร แล้วมี**การแข่งขันหาผู้ชนะรายสัปดาห์**
- เอกสารนี้รับคะแนนต่อจาก `20260821-01-lesson-and-quiz-system` ซึ่งระบุไว้ว่าคะแนนต้องส่งต่อไปยังระบบแรงจูงใจ แต่ยังไม่นิยามว่าแปลงเป็นอะไร — เอกสารนี้เป็นตัวนิยาม

## ความต้องการ (Requirement)

### ก. การแปลงคะแนนเป็นแต้ม

- **ครูเป็นผู้กำหนดว่าแบบทดสอบชุดนั้นคะแนนเต็มเท่าไหร่** แล้ว**ระบบคำนวณคะแนนให้เองตามจำนวนข้อและคะแนนเต็มที่ครูเลือกไว้**
- ครูตั้งค่าเพียงตัวเลขเดียวต่อชุด ไม่ต้องระบุคะแนนรายข้อเอง (สอดคล้องกับข้อจำกัดเรื่องไม่เพิ่มภาระครู)

### ข. ระบบแต้ม — แยกเป็น 2 ยอด

ผู้ใช้ระบุชัดว่า "แต้มไม่มีวันลด" หมายถึงอะไรกันแน่ ให้บันทึกตามนี้:

1. **ยอดแต้มสะสมรวมทั้งหมด — เท่าเดิมเสมอ ไม่มีวันลด** เป็นตัวเลขที่บอกว่าเด็กสะสมมาได้ทั้งหมดเท่าไหร่ตลอดการใช้งาน
2. **ยอดแต้มที่ใช้ได้ — หักออกได้** การพัฒนาร่างต่อไปและการซื้อของแต่งตัวจะหักแต้มออกจากยอดนี้
3. **เมื่อรีเซ็ตตัวละครใหม่ แต้มจะกลับมาเท่าเดิม** คือได้แต้มที่เคยใช้ไปคืนกลับมาทั้งหมด เท่ากับยอดสะสมรวม

### ค. การเติบโตของสัตว์เลี้ยง

- สัตว์เลี้ยง**โตเป็นขั้น** โดยใช้แต้มปลดล็อกขั้นถัดไป
- **มีของแต่งตัว**ที่ซื้อด้วยแต้มได้ด้วย
- **ของแต่งตัวไม่มีผลต่อค่าพลัง** เป็นเรื่องความสวยงาม/ความผูกพันล้วนๆ
- **นักเรียนเลือกชนิดสัตว์เลี้ยงเองได้ตอนเริ่ม และเปลี่ยนชนิดภายหลังได้** (รอบนี้เพิ่มเข้ามาให้ชัดเจน)
- **"เปลี่ยนชนิดสัตว์เลี้ยง" กับ "รีเซ็ตตัวละคร" เป็นเรื่องเดียวกัน** ไม่ใช่ 2 กลไกแยกกัน — เมื่อนักเรียนเปลี่ยนชนิดสัตว์เลี้ยง ตัวละครจะเริ่มขั้นการเติบโตใหม่จากต้น และได้แต้มที่ใช้ไปคืนทั้งหมด (สอดคล้องกับข้อ ข.3 ที่ระบุไว้แล้วว่ายอดแต้มที่ใช้ได้กลับมาเท่ากับยอดสะสมรวม)
- **การแพ้ไม่มีผลเสียใดๆ เลยต่อสัตว์เลี้ยง** — ไม่เสียแต้ม ไม่ลดขั้น สัตว์เลี้ยงไม่เปลี่ยนสภาพ ไม่ว่าจะแพ้กี่ครั้งก็ตาม
- **ของแต่งตัว — ระบุเป็นหมวดไว้ก่อนเท่านั้น ยังไม่ล็อกรายการและราคา** เพราะราคาต้องสัมพันธ์กับเกณฑ์แต้มของขั้นการเติบโตซึ่งยังไม่ล็อก (ของแต่งตัวยังคงไม่มีผลต่อค่าพลังตามที่ระบุไว้ข้างต้น)

### ง. การแข่งขันรายสัปดาห์

- **สัตว์เลี้ยงสู้กันด้วยค่าพลัง**
- **ค่าพลังมาจากขั้นการเติบโตล้วนๆ** ไม่มีปัจจัยอื่นมาปน (ไม่ใช่ของแต่งตัว ไม่ใช่คะแนนของสัปดาห์นั้น) — เหตุผล: ตรงไปตรงมา เด็กเข้าใจทันที และโยงกลับไปที่การเรียนชัดเจน
- **การจับคู่ — เปลี่ยนกลไกในรอบนี้ ไม่ใช่ครูจับคู่ทั้งหมดเหมือนเดิมอีกต่อไป รองรับทั้งนักเรียนเลือกเองและครูจัดการ:**
  1. **นักเรียนเลือกคู่แข่งของตนเอง** (**วิธีหลักที่เพิ่มใหม่ในรอบนี้**) — นักเรียนเป็นผู้เลือกว่าอยากสู้กับใคร
  2. **ครูที่มีเวลา** ตั้งค่าได้ตามใจ และนำการแข่งขันมาเป็นส่วนหนึ่งของคลาสได้ เช่น ในคาบโฮมรูมให้เด็กเลือกว่าอยากสู้กับใคร เพื่อให้เด็กทั้งห้องตื่นเต้นลุ้นไปพร้อมกัน — ภายใต้กลุ่มนี้ยังคงโหมดเดิมไว้ตามที่เคยระบุ: ครูกดสุ่มจับคู่, ครูกดเลือกคู่เอง
  3. **ครูที่ไม่มีเวลา** ใช้ระบบอัตโนมัติจัดการให้ได้ (ระบบจับคู่เองในแต่ละสัปดาห์ โดยครูไม่ต้องเข้าไปยุ่ง)
  - **เหตุผลที่ต้องเพิ่ม "นักเรียนเลือกคู่เอง" เป็นวิธีหลัก:** ครูไม่จำเป็นต้องรับรู้เรื่องสัตว์เลี้ยงของนักเรียน ถ้าครูต้องมานั่งดูว่าใครอยู่ขั้นไหนแล้วเรียงว่าใครสูสีกัน ระบบจะกลายเป็น**เพิ่ม**ภาระครูแทนที่จะ**ผ่อน**ภาระ ซึ่งขัดกับหลักการของเฟสนี้
  - **หลักการที่ผู้ใช้ยืนยัน:** "เราไม่ได้ต้องการความเท่าเทียม แต่เรากำลังส่งเสริมให้เด็กอยากขึ้นไปเท่าเทียมกับเพื่อน" — การเห็นเพื่อนที่แข็งแรงกว่าคือแรงจูงใจ ไม่ใช่ปัญหาที่ต้องกำจัดด้วยการจับคู่ให้สูสี ดู [[20260821-04-teacher-class-overview|20260821-04-teacher-class-overview]] ประกอบ
- **ครูเป็นผู้คุมจังหวะการประกาศผลเอง**
- **โหมดฉายผลการต่อสู้ในห้องเรียน (เพิ่มใหม่ในรอบนี้):** ครูสามารถนำแต่ละรอบการต่อสู้มาฉายในคาบโฮมรูมให้เด็กลุ้นด้วยกันได้ทุกวัน ทำให้การแข่งขันเป็นกิจกรรมร่วมของห้อง ไม่ใช่แค่เด็กเปิดดูผลเอง

### จ. รางวัลของผู้ชนะรายสัปดาห์

- **เบื้องต้นให้เป็นดาวหรือสัญลักษณ์ติดไว้** เพื่อเป็นกำลังใจของนักเรียน
- **ส่วนรางวัลอื่นเปิดกว้างให้ครูตัดสินใจ** เช่น ให้รู้ผู้ชนะก่อนแล้วครูค่อยเลือกรางวัล หรือสะสมไว้จับรางวัลตอนท้ายเทอม หรือแนวทางอื่น — ผู้ใช้ระบุว่า **"เปิดกว้างไว้ก่อน"** ยังไม่ล็อก

### ฉ. ความเป็นธรรมกับเด็กที่ตามเพื่อนไม่ทัน

ผู้ใช้เลือกกลไกคุ้มครอง 2 ข้อ:
1. **แต้มสะสมไม่มีวันลด** แพ้แข่งกี่ครั้งก็ไม่เสียสิ่งที่สะสมไว้ เด็กก้าวหน้าเสมอ ไม่มีการถอยหลัง
2. **ครูคุมจังหวะประกาศผลเอง**

### ช. ค่าพลัง สถานะ และค่าพลังพิเศษประจำสาย (รายละเอียดยังไม่ล็อกในรอบนี้)

- นอกจากค่าพลังพื้นฐาน (มาจากขั้นการเติบโต ตามข้อ ง.) จะมี **ค่าสเตตัส** และ **ค่าพลังพิเศษประจำแต่ละสายของสัตว์เลี้ยง** เพิ่มเข้ามาในกลไกการต่อสู้
- ตัวอย่างค่าสเตตัสที่ผู้ใช้ระบุไว้มีเพียง **3 อย่าง: ไฟไหม้ / ติดพิษ / มึนงง** — **ห้ามเพิ่มรายการอื่นนอกจาก 3 อย่างนี้จนกว่าผู้ใช้จะยืนยันเพิ่ม** และให้ถือว่ารายการยังไม่ครบ (ผู้ใช้อาจเพิ่มในรอบถัดไป)
- **ตัวเลขของค่าพลัง ค่าสเตตัสทั้ง 3 และค่าพลังพิเศษประจำสาย ยังไม่กำหนดในรอบนี้** ผู้ใช้ระบุว่าจะกำหนดภายหลังเพราะยังไม่แน่ใจเรื่องบทเรียน

## ขอบเขต (Scope)

- **อยู่ในขอบเขต:** การแปลงคะแนนเป็นแต้มโดยครูตั้งคะแนนเต็มต่อชุด, ระบบแต้ม 2 ยอด (สะสมรวมไม่ลด / ใช้ได้หักออกได้), การเลือกและเปลี่ยนชนิดสัตว์เลี้ยง (ซึ่งคือการรีเซ็ตตัวละครแล้วได้แต้มคืน), การเติบโตเป็นขั้นด้วยแต้ม, ของแต่งตัวที่ซื้อด้วยแต้มและไม่มีผลต่อค่าพลัง (ระบุเป็นหมวดไว้ก่อน), การแข่งขันรายสัปดาห์ด้วยค่าพลังที่มาจากขั้นการเติบโต, การจับคู่หลายแบบ (นักเรียนเลือกคู่เอง / ครูมีเวลาจัดเป็นกิจกรรมคลาสหรือกดสุ่ม-กดเลือกเอง / ครูไม่มีเวลาใช้ระบบอัตโนมัติ), โหมดฉายผลการต่อสู้ในห้องเรียน, ครูคุมจังหวะประกาศผล, ดาว/สัญลักษณ์และสถิติของผู้ชนะ
- **ไม่อยู่ในขอบเขต:** ระบบบทเรียนและแบบทดสอบ (อยู่ใน `20260821-01-lesson-and-quiz-system`), ระบบล็อกอินและการจัดการรายชื่อนักเรียน, การส่งออกคะแนนเข้าสมุดคะแนนของโรงเรียน, หน้าติดตามของผู้ปกครอง, แคตตาล็อกรางวัลจริงปลายเทอม (ครูตัดสินใจเอง ยังไม่ล็อก)

## Acceptance Criteria

- [ ] ครูกำหนดคะแนนเต็มของแบบทดสอบแต่ละชุดได้ และระบบคำนวณคะแนนตามจำนวนข้อให้เองโดยครูไม่ต้องกรอกรายข้อ
- [ ] ยอดแต้มสะสมรวมของนักเรียนไม่ลดลงจากการกระทำใดๆ ในระบบ
- [ ] การปลดล็อกขั้นถัดไปและการซื้อของแต่งตัวหักจากยอดแต้มที่ใช้ได้ ไม่กระทบยอดสะสมรวม
- [ ] เมื่อนักเรียนรีเซ็ตตัวละคร ยอดแต้มที่ใช้ได้กลับมาเท่ากับยอดสะสมรวม
- [ ] ของแต่งตัวไม่ทำให้ค่าพลังของสัตว์เลี้ยงเปลี่ยนแปลง
- [ ] ค่าพลังที่ใช้ตัดสินการแข่งขันคำนวณจากขั้นการเติบโตเท่านั้น
- [ ] ครูจับคู่แข่งได้ครบทั้ง 3 แบบ (สุ่ม / เลือกเอง / ตั้งให้ระบบทำเองรายสัปดาห์)
- [ ] ครูเป็นผู้กดประกาศผลการแข่งขัน ระบบไม่ประกาศเองโดยครูไม่ได้สั่ง
- [ ] ผู้ชนะรายสัปดาห์ได้ดาวหรือสัญลักษณ์แสดงบนโปรไฟล์
- [ ] ไม่มีกลไกใดในระบบที่ทำให้นักเรียนเสียแต้มสะสมรวม หรือถูกลดขั้นการเติบโตจากการแพ้
- [ ] นักเรียนเลือกคู่แข่งของตนเองได้
- [ ] ครูฉายผลการต่อสู้ให้ทั้งห้องดูร่วมกันได้
- [ ] นักเรียนเลือกชนิดสัตว์เลี้ยงตอนเริ่มได้ และเปลี่ยนชนิดภายหลังได้
- [ ] เมื่อเปลี่ยนชนิดสัตว์เลี้ยง ตัวละครเริ่มขั้นใหม่จากต้นและได้แต้มที่ใช้ไปคืนทั้งหมด
- [ ] การแพ้ไม่ทำให้นักเรียนเสียแต้ม เสียขั้น หรือสัตว์เลี้ยงเปลี่ยนสภาพ
- [ ] ระบบสะสมสถิติผู้ชนะให้ครูดูได้ โดยระบบไม่ผูกกับของรางวัลจริง

## ประเด็นที่ยังไม่ชัดเจน (Open Questions)
