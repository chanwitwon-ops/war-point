# 03 - Task

เก็บ **รายการงานย่อย (Task Breakdown)** ที่แตกออกมาจากแผนงานใน [[../02-plan/index|02-plan]] ให้อยู่ในระดับที่ลงมือทำได้จริง เช่น

- To-do list ของแต่ละฟีเจอร์
- สถานะของงาน (ยังไม่เริ่ม / กำลังทำ / เสร็จแล้ว)
- ผู้รับผิดชอบและ deadline ของแต่ละงาน (ถ้ามี)

เมื่อทำงานเสร็จ ผลลัพธ์ที่เกี่ยวข้องกับการออกแบบให้บันทึกต่อใน [[../../02-design/index|02-design]] และความเคลื่อนไหวสำคัญให้บันทึกใน [[../../05-log/index|05-log]]
