เอกสารนี้แตกความสามารถระดับ high-level (รหัส `FE-XX`) จาก requirement spec ทั้ง 6 ฉบับใน [[01-spec/index|01-spec]] ที่บันทึกไว้ใน [[backlog|backlog]] ทุกรายการต้อง trace กลับไปหา requirement ต้นทางได้ — ไม่มี feature ใดที่ไม่มีที่มาจากเอกสาร spec

หมายเหตุ: `20260821-00-problem-statement` เป็นเอกสารวิเคราะห์ปัญหาตั้งต้น (5 Whys) ไม่ได้ระบุโซลูชัน/ฟีเจอร์ใดๆ จึงไม่มี FE ที่แตกออกมาจากฉบับนี้โดยตรง แต่ทุกกลุ่ม FE ด้านล่างอ้างอิงกลับไปถึงเจตนาของเฟสที่ 1 (แรงจูงใจของเด็ก) ที่เอกสารนี้วางไว้ รอบนี้ spec 00 ปิด Open Question ทั้ง 3 ข้อ (ตัวชี้วัดความสำเร็จเชิงคุณภาพ, ทิศทางโซลูชัน, บทบาทผู้ใช้) แต่ยังไม่ได้ล็อกตัวเลขเป้าหมายของตัวชี้วัด — ดูหัวข้อ "ช่องว่างที่พบ" ท้ายเอกสาร

**หมายเหตุการอัปเดตรอบนี้ (2026-08-21):** เพิ่ม `FE-37` ถึง `FE-71` จาก spec 01, 02, 03 (ฉบับปรับปรุงเพิ่ม AC), spec 04 (ฉบับใหม่ — หน้าภาพรวมของครู) และ spec 05 (ฉบับใหม่ — การส่งออกคะแนน) พร้อมย้าย `FE-34` จากระดับ **Won't** เป็น **Should** เพราะมี spec 05 มารองรับแล้ว และปรับปรุงคำอธิบายของ `FE-26` ให้ตรงกับ Open Question ที่ spec 02 ปิดแล้ว (เปลี่ยนชนิดสัตว์เลี้ยง = รีเซ็ตตัวละคร) — **รหัส `FE-01` ถึง `FE-36` เดิมไม่มีการเปลี่ยนรหัสหรือลบทิ้งแต่อย่างใด** มีเพียงการแก้เนื้อหา/ระดับของ `FE-04`, `FE-26`, `FE-34` ตามที่ระบุไว้ในแต่ละรายการ

**หมายเหตุการอัปเดตเพิ่มเติม (2026-08-21 รอบที่ 2):** `20260821-02-pet-points-and-weekly-arena` เพิ่มหัวข้อ "ค.๑ บันทึกเส้นทางการเติบโต" และ AC อีก 4 ข้อ จึงเพิ่ม `FE-72` ถึง `FE-74` (บันทึกเส้นทางการเติบโต, บันทึกไม่ถูกลบเมื่อรีเซ็ต, จำกัดสัตว์เลี้ยงที่ใช้งานอยู่ได้เพียงตัวเดียว) เข้ากลุ่ม E พร้อมปรับปรุงเนื้อหา `FE-26` ให้เชื่อมโยงกับ 3 รายการใหม่ — **คงรหัส `FE-01` ถึง `FE-71` เดิมไว้ทั้งหมด ไม่เปลี่ยนแปลง** มีเพียงการแก้ไขคำอธิบายของ `FE-26` ในที่เดิม

## เกณฑ์การจัด MoSCoW ของรอบนี้

จัดตามหลัก **"ครบวงจรแรงจูงใจ"** คือดูว่าองค์ประกอบใดจำเป็นให้วงจร ล็อกอิน → ทบทวนบทเรียน → ทำแบบทดสอบ → ได้แต้ม → เลี้ยงสัตว์เลี้ยง ครบรอบเดียวจบโดยไม่ขาดตอน (หลักเกณฑ์นี้ใช้ต่อเนื่องจากรอบก่อน ไม่เปลี่ยน)

- **Must** — ขาดแล้ววงจรแรงจูงใจครบรอบเดียวไม่ได้เลย (MVP)
- **Should** — เพิ่มคุณค่าให้วงจรแรงจูงใจมาก (เช่น การแข่งขันรายสัปดาห์ที่เป็นเป้าหมายรองของเฟส 1) แต่วงจรหลักยังทำงานได้แม้ไม่มี
- **Could** — มีก็ดี กระทบวงจรแรงจูงใจหลักน้อย
- **Won't (รอบนี้)** — spec ประกาศไว้เองว่าอยู่นอกขอบเขต

## ช่องว่างที่พบ (Gap)

- **ยังไม่กำหนดเกณฑ์ผ่าน/ตัวเลขเป้าหมายของตัวชี้วัดความสำเร็จ** — spec 00 ปิดแล้วว่าจะวัดทั้งด้านพฤติกรรมและด้านคะแนน แต่ยังไม่ล็อกตัวเลขเป้าหมายของแต่ละตัวชี้วัด (เช่น เข้าใช้งานกี่ครั้ง/สัปดาห์จึงถือว่าสำเร็จ) ต้องปิดประเด็นนี้ก่อนถึงขั้น `03-testing/01-test-plan/acceptance-criteria.md`
- **จำนวนขั้นการเติบโตของสัตว์เลี้ยงและเกณฑ์แต้มต่อขั้นยังไม่ล็อก** — กระทบ FE-24 โดยตรง ผลกระทบ: ตอนทำ prototype หน้าจอสัตว์เลี้ยงต้องใช้ค่าสมมติ (placeholder) แทนจนกว่าจะล็อกตัวเลขนี้
- **ตัวเลขค่าพลังต่อขั้น ค่าสเตตัสทั้ง 3 (ไฟไหม้ / ติดพิษ / มึนงง) และค่าพลังพิเศษประจำสายยังไม่กำหนด และยังไม่มีสูตรตัดสินแพ้-ชนะ** — กระทบ FE-27 และ FE-45 โดยตรง
- **ความเสี่ยงเรื่องความเป็นธรรมของการแข่งขัน (กระทบ FE-27/FE-30)** — เพราะค่าพลังมาจากขั้นการเติบโตล้วนๆ ไม่มีปัจจัยสุ่ม และไม่มีกฎบังคับให้จับคู่ตามระดับใกล้เคียงกัน บรรเทาบางส่วนแล้วด้วย FE-42 (นักเรียนเลือกคู่แข่งเอง) แต่กรณีที่ครูเลือกโหมด FE-30 (ระบบจับคู่เองอัตโนมัติ) ยังไม่มีกฎป้องกันคู่ที่ห่างชั้นมาก ต้องเฝ้าดูตอนทดสอบจริง
- **ยังไม่กำหนดจำนวนครั้งที่กรอก PIN ผิดได้และระยะเวลาที่ล็อค** — กระทบ FE-48 โดยตรง
- **ยังไม่ระบุจำนวนหลักของ PIN** — spec 03 ระบุเพียงว่าเป็นตัวเลข ยังไม่ล็อกจำนวนหลัก
- **ยังไม่ระบุขอบเขตสิทธิ์ (scope) ที่ระบบขอจาก Google** ทั้งตอนอ่านรายชื่อผ่านลิงก์ Google Sheets (FE-50) และตอนเขียนคะแนนกลับเข้า Google Sheets (FE-66) — สิทธิ์เขียนอันตรายกว่าสิทธิ์อ่าน ต้องระบุให้ชัดก่อนพัฒนา และยังไม่ระบุว่าจะดึงข้อมูลรายชื่อซ้ำจากลิงก์เมื่อไหร่
- **ยังไม่ระบุว่าถ้าครูส่งคะแนนซ้ำรอบสองเข้า Google Sheets จะเขียนทับค่าเดิม เพิ่มคอลัมน์ใหม่ หรือถามครูก่อน** — กระทบ FE-66/FE-71
- **ยังไม่ระบุว่าจะเกิดอะไรขึ้นถ้าครูเปลี่ยนโครงสร้างชีทหลังจากตั้งค่าคอลัมน์ปลายทางไว้แล้ว** (คอลัมน์เลื่อน แถวสลับ) — กระทบ FE-68
- **ยังไม่ระบุรูปแบบไฟล์ที่ดาวน์โหลดคะแนนได้** — กระทบ FE-67
- **ยังไม่ระบุว่าคะแนนที่ส่งออกใช้คะแนนดิบหรือคะแนนที่ปรับตามคะแนนเต็มที่ครูตั้งไว้** — กระทบ FE-64/FE-65 ต่อเนื่องกับ FE-21
- **ยังไม่ตัดสินว่าจะส่งออกคะแนนของงานที่ครูตรวจเอง (ใบงาน/ชิ้นงาน) ด้วยหรือไม่** — กระทบ FE-64/FE-65 ที่เชื่อมกับเส้นทาง FE-13/FE-14/FE-17
- **ยังไม่ระบุแหล่งที่ AI ค้นคลิปและเรื่องลิขสิทธิ์ของคลิปที่เสนอ** — กระทบ FE-11 (ปิดเฉพาะเรื่องความเหมาะสม/การอนุมัติของครูแล้วด้วย FE-39 แต่เรื่องแหล่งที่มาและลิขสิทธิ์ยังเปิดอยู่)
- **ยังไม่ระบุเสียงที่ใช้อ่านออกเสียงภาษาไทย** — กระทบ FE-10 (ปิดเฉพาะขอบเขตแหล่งข้อความที่อ่านได้แล้ว แต่ชนิดเสียงยังไม่ระบุ)
- **ของแต่งตัวยังไม่ล็อกรายการและราคา** — เพราะราคาต้องสัมพันธ์กับเกณฑ์แต้มของขั้นการเติบโตซึ่งยังไม่ล็อก กระทบ FE-25
- **เกณฑ์ของคำว่า "ไม่เข้าใช้งานนาน" ยังไม่กำหนดเป็นจำนวนวัน และยังไม่ระบุว่าครูตั้งเกณฑ์นี้เองได้หรือไม่** — กระทบ FE-59
- **สัญลักษณ์เตือนบนแถวนักเรียนยังไม่ระบุว่ามีกี่แบบและแต่ละแบบหมายถึงอะไร** (เช่น ยังไม่ส่งงาน / ไม่เข้าใช้งาน / คะแนนต่ำ ควรใช้สัญลักษณ์เดียวหรือแยกกัน) — กระทบ FE-60
- **ตัวเลือกการเรียงลำดับและการกรองที่ต้องมีจริงในหน้าภาพรวมของครูยังไม่ระบุเป็นรายการ** — กระทบ FE-62
- **ครูจะเทียบรหัสประจำตัวกลับเป็นตัวนักเรียนอย่างไรในหน้าจอจริงยังต้องดูตอนใช้งานจริง** — spec 03 ปิดบางส่วนแล้วด้วยการใช้รหัสโรงเรียน+ชื่อเล่น แต่ยังต้องเฝ้าดูว่าครูสับสนหรือไม่โดยเฉพาะในหน้าภาพรวม (FE-57/FE-58)
- **หมายเหตุปิดแล้ว:** ช่องว่างเดิมที่เคยบันทึกว่า "ไม่มี requirement ครอบเรื่องครูดูภาพรวมทั้งห้อง" — **ปิดแล้วเมื่อ 2026-08-21** ด้วย `20260821-04-teacher-class-overview` (ดู FE-57 ถึง FE-62)
- **จำนวนขั้นการเติบโตยังไม่ล็อกและแนวทาง "แยกแกนขั้นวิวัฒนาการออกจากความเปลี่ยนแปลงรายสัปดาห์" ยังไม่ตัดสิน (เพิ่มใหม่ 2026-08-21 รอบที่ 2)** — ความต้องการเดิมของผู้ใช้คือให้สัตว์เลี้ยงพัฒนาร่างทุกสัปดาห์หรือทุกครั้งที่สอบเก็บคะแนน เพื่อไม่ให้การต่อสู้รอบถัดไปซ้ำซาก แต่ขัดกับงบอาร์ตเวิร์ก (เปลี่ยนร่างทุกสัปดาห์ต้องผลิตอาร์ตจำนวนมากคูณทุกสายพันธุ์) และขัดกับความผูกพันของเด็กถ้าถึงร่างเต็มวัยเร็วเกินไป (ช่วงที่เหลือของเทอมจะไม่มีอะไรให้รอ) แนวทางที่หารือไว้คือแยกแกน "ขั้นวิวัฒนาการ" (น้อยครั้ง ต้นทุนอาร์ตสูง) ออกจาก "ความเปลี่ยนแปลงรายสัปดาห์" (บ่อยครั้ง ต้นทุนอาร์ตต่ำ เช่น ค่าสเตตัส/พลังพิเศษ/ของแต่งตัว) แต่ยังไม่ตัดสิน — กระทบ FE-24, FE-72 โดยตรง (ต้องล็อกจำนวนขั้นก่อนจึงจะรู้ว่าบันทึกเส้นทางการเติบโตควรบันทึกกี่จุด)
- **ยังไม่ระบุว่าบันทึกเส้นทางการเติบโต (FE-72) แสดงอะไรบ้างและให้ใครดูได้ (เพิ่มใหม่ 2026-08-21 รอบที่ 2)** — ยังไม่ระบุว่าแสดงเฉพาะร่างที่เคยไปถึงสูงสุด หรือแสดงเส้นทางทั้งหมดที่เดินผ่าน รวมถึงยังไม่กำหนดจำนวนรอบที่เก็บประวัติย้อนหลัง (เก็บทุกครั้งที่รีเซ็ตหรือเฉพาะครั้งล่าสุด) และยังไม่ระบุสิทธิ์การเข้าถึง (นักเรียนเจ้าของเท่านั้น เพื่อนในห้อง หรือครู) — `20260821-04-teacher-class-overview` ระบุไว้แล้วว่าหน้าภาพรวมของครูไม่แสดงข้อมูลสัตว์เลี้ยง แต่ไม่ได้ตัดสินเรื่องบันทึกเส้นทางการเติบโตนี้โดยตรง
