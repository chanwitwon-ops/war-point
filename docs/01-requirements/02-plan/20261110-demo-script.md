## เป้าหมายของเดโม (ผู้ใช้ยืนยันแล้ว)

1. เดินระบบจริงตั้งแต่ล็อกอิน **ทั้งครูและนักเรียน** — เข้ามาเจอหน้าไหน ทำอะไรได้ ออกข้อสอบยังไง / นักเรียนเข้ามาเจออะไร ต้องทำอะไร
2. สัตว์เลี้ยงใช้ **ร่างสุดท้ายเท่านั้น** (โควต้าคลิปวิดีโอน้อย)
3. **การต่อสู้คือจุดขาย** — ต้องลุ้นกว่าระบบต่อสู้ของ Smart Classroom
4. โดยรวมต้องแสดงผลได้ไม่น้อยกว่า Smart Classroom

เรื่องที่จะเล่าบนเวที (ร้อยทุกฉากเข้าด้วยกัน): *ครูออกข้อสอบเร็วขึ้นและไม่ต้องหอบไปตรวจที่บ้าน → เด็กมีเหตุผลที่จะทำงาน "ตอนนี้" เพราะคะแนนกลายเป็นสัตว์เลี้ยงที่โตขึ้น → สัตว์เลี้ยงได้ขึ้นเวทีประลอง และชื่อได้ขึ้นกระดาน*
