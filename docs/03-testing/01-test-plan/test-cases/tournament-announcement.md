- **ครอบ FE:** FE-31 (ครูกดประกาศผล — เฉพาะ AC-FE-31-3~19 ของทัวนาเมนต์), FE-43 (โหมดฉายผลในคาบโฮมรูม — AC-FE-43-1/2) — ผูกไปก่อนเพราะ spec 08 ยังไม่มี FE ของตัวเอง ดู Coverage Gap G-18

- **ข้อจำกัดที่ต้องอ่านก่อนรัน:**

  - TC-FE-31-006 ต้องรันด้วย **harness ทดสอบสิทธิ์ / Firestore rules** ไม่ใช่ผ่านหน้าจอ
  - ผู้ชนะแต่ละคู่มาจาก engine จริง ไม่ใช่ค่าตายตัว — ให้ผู้ทดสอบจดผู้ชนะที่เห็นจริงเป็น W1 (คู่ 1), W2 (คู่ 2), WF (รอบชิง) ระหว่างรัน แล้วใช้ตรวจ Expected Result
