## FE-20 — นักเรียนทำแบบทดสอบ

### TC-FE-20-001 — นักเรียนตอบครบทุกข้อและส่งคำตอบสำเร็จ

**อ้างอิง:** AC-FE-20-1, FE-20, UJ-01 (node G/H/I), spec 01 หัวข้อ Acceptance Criteria
**ประเภท:** Happy path
**Pre-conditions:** ล็อกอินด้วยรหัส `3001` / PIN `1234` สำเร็จแล้ว อยู่ที่หน้า "ทำแบบทดสอบปรนัย" ชุด "แบบทดสอบปรนัย: การคูณเลข" (5 ข้อ) ยังไม่เคยส่งคำตอบมาก่อน
**Test Data:** เลือกคำตอบครบทั้ง 5 ข้อ (ถูกหรือผิดก็ได้ เพราะ AC นี้ทดสอบการ "ส่งคำตอบสำเร็จ" ไม่ใช่การคำนวณคะแนน)

| # | ขั้นตอน | Expected Result |
|---|---|---|
| 1 | เลือกคำตอบข้อใดก็ได้ให้ครบทั้ง 5 ข้อ | ทุกข้อมีตัวเลือกถูกเลือกไว้ ปุ่ม "ส่งคำตอบ" ยังปรากฏอยู่ที่ท้ายหน้า |
| 2 | กดปุ่ม "ส่งคำตอบ" | มีข้อความแจ้งเตือน (toast) ปรากฏขึ้นว่า "ส่งคำตอบแล้ว ระบบตรวจให้คะแนนอัตโนมัติ" |
| 3 | สังเกตส่วนท้ายของหน้าจอหลังส่งคำตอบ | ปุ่ม "ส่งคำตอบ" หายไป และมีปุ่ม "ดูผลคะแนน" ปรากฏขึ้นแทนที่ให้กดต่อได้ |

**Actual Result:** _(ว่าง — บันทึกที่ docs/03-testing/02-test-result/)_

### TC-FE-20-002 — ไม่สามารถส่งคำตอบได้เมื่อตอบไม่ครบทุกข้อ

**อ้างอิง:** AC-FE-20-2, FE-20, UJ-01 (node G/H), spec 01 หัวข้อ Acceptance Criteria
**ประเภท:** Negative
**Pre-conditions:** ล็อกอินสำเร็จแล้ว อยู่ที่หน้า "ทำแบบทดสอบปรนัย" ชุดเดียวกัน (5 ข้อ) ยังไม่เคยส่งคำตอบมาก่อน
**Test Data:** เลือกคำตอบเพียง 3 จาก 5 ข้อ (เว้นข้อ 4 และข้อ 5 ไว้)

| # | ขั้นตอน | Expected Result |
|---|---|---|
| 1 | เลือกคำตอบข้อ 1–3 เท่านั้น ปล่อยข้อ 4 และข้อ 5 ว่างไว้ | ข้อ 1–3 มีตัวเลือกถูกเลือกไว้ ข้อ 4–5 ยังไม่มีตัวเลือกใดถูกเลือกเลย |
| 2 | กดปุ่ม "ส่งคำตอบ" | มีข้อความแจ้งเตือน (toast) ปรากฏขึ้นว่า "กรุณาเลือกคำตอบให้ครบทุกข้อก่อนส่ง" |
| 3 | สังเกตหน้าจอหลังข้อความแจ้งเตือนหายไป | ยังคงอยู่ที่หน้า "ทำแบบทดสอบปรนัย" เดิม ปุ่ม "ส่งคำตอบ" ยังปรากฏอยู่เหมือนเดิม ปุ่ม "ดูผลคะแนน" **ไม่** ปรากฏขึ้น ไม่มีคะแนนหรือการส่งคำตอบใดถูกบันทึก |

**Actual Result:** _(ว่าง — บันทึกที่ docs/03-testing/02-test-result/)_

## FE-33 — รองรับการใช้งานทั้งบนมือถือและจอขนาดใหญ่

### TC-FE-33-001 — หน้าจอหลักของนักเรียนใช้งานได้บนความกว้างจอระดับมือถือโดยไม่ต้องเลื่อนซ้าย-ขวา

**อ้างอิง:** AC-FE-33-1, FE-33, spec 01, DESIGN.md ข้อ 4.6
**ประเภท:** Happy path
**Pre-conditions:** เปิดไฟล์ `index.html` ของ prototype v1 ด้วยเบราว์เซอร์ แล้วตั้งความกว้างหน้าต่าง/responsive mode ไว้ที่ **375px** (ขนาดมือถือทั่วไป) ก่อนเริ่มทำตามขั้นตอน
**Test Data:** รหัสประจำตัว `3001` / PIN `1234`, ชุดแบบทดสอบ "แบบทดสอบปรนัย: การคูณเลข" (5 ข้อ)

| # | ขั้นตอน | Expected Result |
|---|---|---|
| 1 | เปิดหน้า "เข้าสู่ระบบ War Point" ที่ความกว้างจอ 375px แล้วสังเกตขอบล่างของหน้าต่างเบราว์เซอร์ | ฟอร์มกรอกรหัสประจำตัว, PIN และปุ่ม "เข้าสู่ระบบ" แสดงครบภายในความกว้าง 375px ไม่มีแถบเลื่อนแนวนอน (horizontal scrollbar) ปรากฏที่ขอบล่างของหน้าต่างเลย |
| 2 | กรอกรหัส `3001` / PIN `1234` แล้วกดปุ่ม "เข้าสู่ระบบ" จนเข้าสู่หน้า "ทำแบบทดสอบปรนัย" | เข้าสู่หน้า "ทำแบบทดสอบปรนัย" สำเร็จ ยังอยู่ที่ความกว้างจอ 375px เดิม ไม่มีแถบเลื่อนแนวนอนปรากฏ |
| 3 | เลือกคำตอบให้ครบทั้ง 5 ข้อแล้วกด "ส่งคำตอบ" ที่ความกว้างจอเดิม 375px | คำถาม ตัวเลือกคำตอบ และปุ่มทั้งหมดแสดงครบภายในความกว้าง 375px ตลอดขั้นตอน ไม่ต้องเลื่อนซ้าย-ขวา (horizontal scroll) ที่หน้าจอนี้เลยแม้แต่ครั้งเดียว |

**Actual Result:** _(ว่าง — บันทึกที่ docs/03-testing/02-test-result/)_

### TC-FE-33-002 — หน้าจอเดียวกันแสดงผลถูกต้องบนความกว้างจอระดับคอมพิวเตอร์ของโรงเรียน

**อ้างอิง:** AC-FE-33-2, FE-33, spec 03, DESIGN.md ข้อ 4.6
**ประเภท:** Edge case
**Pre-conditions:** เปิดไฟล์ `index.html` ของ prototype v1 เดิมด้วยเบราว์เซอร์ แล้วตั้งความกว้างหน้าต่าง/responsive mode ไว้ที่ **1280px ขึ้นไป** (จำลองแท็บเล็ต/คอมพิวเตอร์ของโรงเรียน) ก่อนเริ่มทำตามขั้นตอน
**Test Data:** รหัสประจำตัว `3001` / PIN `1234`, ชุดแบบทดสอบ "แบบทดสอบปรนัย: การคูณเลข" (5 ข้อ)

| # | ขั้นตอน | Expected Result |
|---|---|---|
| 1 | เปิดหน้า "เข้าสู่ระบบ War Point" ที่ความกว้างจอ 1280px | ฟอร์มล็อกอินแสดงอยู่กึ่งกลางจอ ไม่มีข้อความหรือปุ่มใดล้นขอบหรือซ้อนทับกัน และไม่มีแถบเลื่อนแนวนอนปรากฏที่ขอบล่างของหน้าต่างเลย |
| 2 | กรอกรหัส `3001` / PIN `1234` แล้วกด "เข้าสู่ระบบ" จนเข้าสู่หน้า "ทำแบบทดสอบปรนัย" ที่ความกว้างจอเดิม 1280px | คำถามและตัวเลือกคำตอบทั้ง 5 ข้อแสดงครบถ้วน ไม่มีองค์ประกอบใดล้นขอบจอหรือซ้อนทับกัน และไม่มีแถบเลื่อนแนวนอนปรากฏ เช่นเดียวกับผลที่เห็นบนความกว้าง 375px ใน TC-FE-33-001 |
