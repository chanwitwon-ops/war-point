## FE-44 — นักเรียนเลือกสายพันธุ์สัตว์เลี้ยงตอนซื้อไข่ (3 สาย)

### TC-FE-44-001 — นักเรียนเลือกสายพันธุ์ของไข่ได้สำเร็จตอนซื้อไข่

**อ้างอิง:** AC-FE-44-1, FE-44, FE-75
**ประเภท:** Happy path
**Pre-conditions:** นักเรียนกำลังจะซื้อไข่ ยังไม่มีสัตว์เลี้ยงที่ใช้งานอยู่
**Test Data:** ตัวเลือกสายพันธุ์ 3 สาย: ไข่มีปีก / ไข่มีขา / ไข่มีหาง

| # | ขั้นตอน | Expected Result |
|---|---|---|
| 1 | เปิดหน้าจอซื้อไข่ | เห็นตัวเลือกสายพันธุ์ครบ 3 สาย: "ไข่มีปีก", "ไข่มีขา", "ไข่มีหาง" |
| 2 | เลือกสายพันธุ์ "ไข่มีหาง" แล้วยืนยัน | ระบบกำหนดสายพันธุ์ "ไข่มีหาง" ให้กับไข่ที่กำลังจะซื้อ ก่อนดำเนินการหักแต้ม (ดู FE-75) |

**สถานะ prototype:** ยังรันไม่ได้ — prototype v1 ให้เลือกสายพันธุ์ตอนเปลี่ยนชนิดภายหลัง ไม่ใช่ตอนซื้อไข่ และไม่มีป้าย "ไข่มีปีก/ไข่มีขา/ไข่มีหาง"
**Actual Result:** _(ว่าง)_

### TC-FE-44-002 — ตัวเลือกสายพันธุ์ทั้ง 3 สายมีทั้งสีและป้ายชื่อกำกับเสมอ (ไม่สื่อด้วยสีเดียว)

**อ้างอิง:** AC-FE-44-2, FE-44, DESIGN.md ข้อ 4.4
**ประเภท:** Edge case
**Pre-conditions:** เปิดหน้าจอเลือกสายพันธุ์ตอนซื้อไข่
**Test Data:** ตัวเลือกทั้ง 3 สาย

| # | ขั้นตอน | Expected Result |
|---|---|---|
| 1 | ตรวจสอบ DOM ของแต่ละตัวเลือกสายพันธุ์ | ทุกตัวเลือกมีทั้งวงกลมสีประจำสาย (species-swatch) และข้อความป้ายชื่อลักษณะไข่ (เช่น "ไข่มีปีก") ปรากฏคู่กันเสมอ ไม่มีตัวเลือกใดสื่อความแตกต่างด้วยสีเพียงอย่างเดียว |

**สถานะ prototype:** ยังรันไม่ได้ — โครงสร้าง `species-swatch` มีอยู่จริงใน prototype v1 (ใช้กับ 5 สายที่มีอยู่) แต่ยังไม่มีป้ายชื่อลักษณะไข่ 3 สายตามที่ล็อกแล้ว
**Actual Result:** _(ว่าง)_

## FE-76 — ไข่มีค่าสเตตัสตั้งต้น 50 และลงแข่งขันได้

### TC-FE-76-002 — ไข่ปรากฏเป็นตัวเลือกที่แข่งขันได้ในหน้าเลือกคู่แข่งของสัปดาห์นี้

**อ้างอิง:** AC-FE-76-2, FE-76, FE-42
**ประเภท:** Happy path
**Pre-conditions:** นักเรียนมีสัตว์เลี้ยงที่ยังอยู่ในขั้นไข่
**Test Data:** เปิดหน้าเลือกคู่แข่งของสัปดาห์นี้ (อารีน่า)

| # | ขั้นตอน | Expected Result |
|---|---|---|
| 1 | เปิดหน้าอารีน่าแล้วเลือกคู่แข่ง | นักเรียนเลือกลงแข่งขันได้ตามปกติแม้สัตว์เลี้ยงยังเป็นไข่ ไม่มีข้อความหรือเงื่อนไขใดกันไข่ออกจากการแข่งขัน |
| 2 | ยืนยันคู่แข่งแล้วรอผล | ระบบดำเนินการต่อเหมือนสัตว์เลี้ยงที่โตแล้วทุกประการ |

**สถานะ prototype:** ยังรันไม่ได้ — ไม่มีขั้นไข่ให้ทดสอบ
**Actual Result:** _(ว่าง)_

### TC-FE-76-003 — ไข่ไม่ถูกกันออกจากรายชื่อที่ระบบใช้จับคู่อัตโนมัติ

**อ้างอิง:** AC-FE-76-3, FE-76, FE-30
**ประเภท:** Negative
**Pre-conditions:** ในห้องเรียนมีนักเรียนบางคนที่สัตว์เลี้ยงยังอยู่ในขั้นไข่ และครูเปิดใช้งานโหมดระบบจับคู่อัตโนมัติรายสัปดาห์
**Test Data:** รายชื่อนักเรียนที่มีทั้งสัตว์เลี้ยงที่โตแล้วและที่ยังเป็นไข่

| # | ขั้นตอน | Expected Result |
|---|---|---|
| 1 | ครูเปิดใช้งานโหมด "ตั้งให้ระบบจับคู่เองทุกสัปดาห์" | ระบบสร้างคู่แข่งของสัปดาห์นี้ |
| 2 | ตรวจสอบรายชื่อคู่แข่งที่ถูกจับคู่ | นักเรียนที่สัตว์เลี้ยงยังเป็นไข่ถูกจับคู่แข่งขันร่วมด้วยเช่นเดียวกับนักเรียนคนอื่น ไม่มีนักเรียนคนใดถูกข้ามหรือกันออกเพราะสัตว์เลี้ยงยังเป็นไข่ |

**สถานะ prototype:** ยังรันไม่ได้ — prototype v2 ไม่มีแนวคิดขั้นไข่ในข้อมูลจำลอง (การจับคู่ในหน้าจัดการแข่งขันของครูใช้เพียงรหัส+ชื่อเล่นอยู่แล้วตามกฎ "ครูไม่เห็นข้อมูลสัตว์เลี้ยง" จึงไม่มีจุดใดที่จะกันไข่ออกได้อยู่แล้วในทางเทคนิค — แต่ยังไม่มีข้อมูลทดสอบที่จำลองกรณี "นักเรียนบางคนสัตว์เลี้ยงยังเป็นไข่" ให้ยืนยันชัดเจน)
**Actual Result:** _(ว่าง)_
