## หมายเหตุสำคัญเรื่อง prototype (อ่านก่อนใช้ไฟล์นี้)

`v3-20260823-student-egg-economy/index.html` หน้า `screen-pet` โซน "ดูแลสัตว์เลี้ยงประจำวัน" มีกลไกครบตาม spec แล้ว — **ทุก test case ในไฟล์นี้รันได้จริงบน prototype v3 วันนี้** ไม่ต้องรอ prototype รอบถัดไป องค์ประกอบ UI จริงที่ใช้อ้างอิงในขั้นตอนด้านล่าง:

| องค์ประกอบ | ข้อความ/ปุ่มจริงในหน้า `screen-pet` |
|---|---|
| ปุ่มให้อาหาร | `ให้อาหาร` (`data-care-action="feed"`) |
| ปุ่มอาบน้ำ | `อาบน้ำ` (`data-care-action="bathe"`) |
| ปุ่มลูบหัว | `ลูบหัว` (`data-care-action="pat"`) |
| ปุ่มเล่น/ออกกำลังกาย | `เล่น/ออกกำลังกาย` (`data-care-action="play"`) |
| ข้อความอิ่มแล้ว (toast) | `ตัวละครอิ่มแล้ว` |
| ข้อความถึงเพดานรวม (toast) | `วันนี้ดูแลเต็มที่แล้ว พรุ่งนี้ค่อยมาใหม่นะ` |
| ตัวเลขโควตาวันนี้ | `โควตาวันนี้: X / 10 วันนี้` (id `care-quota-text`) |
| ตัวเลขยอดสะสมรวม | `ยอดสะสมรวม: X หน่วย` (id `care-total-text`) |
| ปุ่ม QA จำลองวันใหม่ | `จำลองวันใหม่ (รีเซ็ตความหิว+โควตาวันนี้)` (id `qa-new-day-apply`, อยู่หัวไฟล์ในแถบเครื่องมือทดสอบ) |
| ข้อความยืนยันหลังกดจำลองวันใหม่ (toast) | `จำลองวันใหม่แล้ว — ความหิวและโควตาวันนี้ของค่าความผูกพันรีเซ็ตกลับเป็น 0 (ยอดสะสมรวมไม่เปลี่ยนแปลง)` |
| ปุ่มรีเซ็ต/เปลี่ยนสายพันธุ์ | `รีเซ็ต / เปลี่ยนสายพันธุ์ (เริ่มใหม่ที่ขั้นไข่)` (id `btn-open-reset-pet`) |
| ยอดแต้มที่ใช้ได้/สะสมรวม (แถบบนสุด) | `สะสมรวม X` และ `ใช้ได้ X` |
| ยอดสเตตัสต่อสู้ (ในหน้า screen-pet) | `แต้มสเตตัสรวม: X / 250` พร้อมป้าย `ความเร็ว X`, `พละกำลัง X`, `ความแม่นยำ X` |

**ค่าล็อกแล้วที่ใช้ในไฟล์นี้ (ห้ามเปลี่ยน):** `careFeedCapPerDay = 3` (ให้อาหารสำเร็จได้สูงสุด 3 ครั้ง/วัน), `careDailyQuotaCap = 10` (เพดานรวมค่าความผูกพัน/วัน), `careBondingPerAction = 1` (+1 หน่วย/ครั้ง เท่ากันทุก action)
