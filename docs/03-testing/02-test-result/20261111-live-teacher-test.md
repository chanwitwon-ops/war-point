- **ที่ลบ:**
  - `quizAttempts`: seed `att001–att005` + งาน Playwright ของขวานฟ้า 13 ชิ้น (ส่ง 2026-09-25 10:15–10:19)

- **ที่เก็บไว้:** ชุด "แบบทดสอบเรื่องสามก๊ก …" (ครูสร้างด้วย AI), งานสามก๊กของขวานฟ้า 09:47 (8) และเหินฟ้า 09:55 (10) — ผู้ใช้ยืนยันว่าเป็นการทดลองจริงของผู้ใช้เองทั้งฝั่งครูและนักเรียน (ไม่ใช่ Playwright), ชุดทดสอบ "[ทดสอบระบบ 2026-11-11] …", บัญชีผู้ใช้ทุกบัญชี (`users` ลบไม่ได้ตาม rules)
